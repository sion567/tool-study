# CORDIC 算法

## 一句话

把任意角拆成一串固定微角 atan(2⁻ⁱ) 的加减，只用加法和移位就能算 sin/cos。

## 不变量

- 残差 z_{i+1} = z_i − d·atan(2⁻ⁱ)，d = sign(z)：|z| 单调缩到 0
- 微旋转是"伪旋转"（省掉 cos 因子）→ 向量长度涨 1/K 倍，收尾统一乘 K ≈ 0.60725

## 直觉

37° = 26.565° + 7.125° + 3.576° + ...（每步按残差正负加减下一个更小的微角）

- 第 i 步微角 ≈ 45°/2ⁱ，误差上界每步减半 → n 步精度 2⁻ⁿ 量级
- 乘 2⁻ⁱ 在硬件里就是**移位**，乘法器全省——计算器和 FPGA 的标配

## 伪旋转公式

```
x' = x − d·y·2⁻ⁱ
y' = y + d·x·2⁻ⁱ
```

真实旋转矩阵里还有个 cos 因子，CORDIC 故意丢掉它——长度会逐步膨胀，
最后一步统一乘 K = Π√(1+2⁻²ⁱ) ≈ 0.60725 归一回单位圆。

## 怎么练

- 白纸推：目标 30°，写出前 4 步的 d 序列和残差
- 思考：为什么微角表可以预先烧死在 ROM 里
- 延伸：同一套旋转还能算 atan、开方、ln——换个模式而已
