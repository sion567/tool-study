# 位图判重

## 一句话

一个 bit 记一个数见没见过——白 = 没见过，黑 = 见过，红闪 = 重复。

## 画面怎么读

- **左侧**：原始数据列表，橙色 = 当前正在读的数
- **右侧**：BitSet 格子一排，白色 = 0（没见过），黑色 = 1（见过），红圈 = 刚发现的重复
- **堆面板**：`BitSet(8b)` 实物化，每个 bit 的值逐帧可见

## 帧序列（对应你描述的四帧）

1. **读取**：当前数字橙色高亮
2. **检查**：BitSet 对应位置——白还是黑？
3. **白 → 变黑**：第一次遇到，标记为「见过」
4. **黑 → 红闪**：第二次遇到 → **找到重复！**

## 不变量（意图层）

- `bit[x] = 1 ⟺ x 出现过`——查重从两两比较 O(n²) 变成一次下标访问 O(1)，代价是 bit 的空间
- 空间对比：6 个 int（24 字节）→ 8 个 bit（1 字节）——**压缩比 24:1**
- 如果内存更小（1MB = 8×10⁶ bit），就分桶：每个桶覆盖一段值域，逐桶处理（外部排序思路）
