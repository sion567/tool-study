# 蒙特卡洛求 π

## 一句话

往单位正方形撒随机点，**圆内点数/总点数 ≈ π/4**——用随机性算确定值。

## 不变量

点均匀分布 → P(落入四分之一圆) = 面积比 = π/4。
π ≈ 4 × 圆内点数 / 总点数。

## 画面读法

- 蓝点 = 圆内，橙点 = 圆外，绿弧 = 四分之一圆
- 点数 100 → 6300：估计从 3.2 级别的粗糙值逐步咬住 3.1416

## 收敛的脾气

误差 ~ **1/√n**：点数翻 **4** 倍，精度才翻 1 倍——收敛慢但**永不出错、与维度无关**。
100 维积分数值网格爆炸，蒙特卡洛照常工作。

## 工程要点

- **固定随机种子** = 可复现 = 可调试 = 可测试（本演示用种子 42）
- 同一思想今天叫：蒙特卡洛积分、物理模拟、AI 采样——起源是 1777 年 Buffon 投针

## 怎么练

- 改种子看估计怎么变（每颗种子是一个平行宇宙）
- 思考：为什么不能靠"无限撒点"得到无限精度？（浮点与 1/√n 的双重墙）
