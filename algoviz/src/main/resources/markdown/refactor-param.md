# 重构·引入参数对象（Introduce Parameter Object）

## 一句话

总是结伴出现的参数 = 概念上是一个东西——**打包成对象，签名从此稳定**。

## 反例痛点

`register(name, age, addr, phone, email)`：

- 调用方背顺序——`age` 和 `phone` 传反编译器不吭声
- 新增"微信号" → 签名 5 参变 6 参 → **全项目调用点逐个改**

## 正例

```
register(UserInfo u)     // 签名从此不变
```

- 加字段只动 UserInfo 内部，调用点零修改
- 类型系统顺带管住"传反"这类错——类型不对直接编译失败

## 判据

- 几个参数总是一起传、一起变化 → 它们是被拆散的一个对象
- 参数超过 3 个就闻一闻——里面是不是藏着一个没被命名的概念

## 怎么练

- 找参数最多的方法，问"哪几个参数总是结伴？"——打包它，用 record 最省事
