# GAN 生成对抗

## 一句话

G 伪造数据骗 D，D 尽力分辨真假——**对抗中共同进化**，纳什均衡处 D 准确率 = 50%。

## 不变量

```
min_G max_D  E[log D(x)] + E[log(1 − D(G(z)))]
```

## 演示剧本

真实分布 = 半径 1 的圆环（蓝）；生成器从半径 3 的外圈出发（橙）：
- 轮 1：半径 2.3，D 准确率 0.76
- 轮 4：半径 1.0（贴住真实环），D 准确率 0.52 ≈ 瞎猜

D 瞎猜 = G 毕业：生成分布 ≈ 真实分布。

## 训练为什么难

G/D 任何一方过强都会崩——学习率平衡、"半个 D 步"、梯度惩罚……
调 GAN 是出了名的玄学。

## 怎么练

- 白纸推：D 完美（真=1 假=0）时 G 的梯度是什么？（全部指向真实分布）
- 应用：人脸生成、风格迁移、超分辨率——同一个博弈换一个像素空间
