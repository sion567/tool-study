# 力学·抛体运动

## 一句话

水平匀速 + 竖直上抛 = **抛物线**；射程 R = v²sin(2θ)/g——45° 独占最大射程。

## 不变量

- 水平方向：匀速直线（没有力）
- 竖直方向：匀加速（只有 g）
- 两个分量**互不干扰**——伽利略把「下落」从「前进」里剥离了出来
- R = v²sin(2θ)/g：30° 与 60° 射程相同（sin2θ 对称），45° 是峰值

## 画面读法

- 蓝线 = 弹丸轨迹（一条抛物线），橙点 = 弹丸当前位置
- 绿虚线 = 60° 对照轨迹：与 45° 落点相同，但飞得更高、更久
- 堆里：飞行时间 T = 2v₀sinθ/g——「飞多远 = 水平速度 × 留空时间」

## 为什么 45° 最远

- sin(2θ) 在 2θ=90° 处取最大值 → θ=45°
- 30° 和 60° 的 sin(2θ) 相等 → 射程相同：一个平直、一个高抛，殊途同归

## 怎么练

- 白纸算：v₀ 翻倍，射程翻几倍？（4 倍——R ∝ v²，这就是炮口初速的军备竞赛）
- 思考：月球上（g 小）同一炮打多远？（6 倍——g 在分母）
- 冷知识：空气阻力会把最优角压到 45° 以下——标枪运动员实际用 ≈36°
