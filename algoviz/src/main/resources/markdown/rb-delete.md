# 红黑树删除

## 一句话

LLRB 删除 = **先喂红（moveRed 借侄）后修复（fixup 逆序三步）**——与插入同源，性质每步不破。

## 不变量

- 删除黑节点前必须把路径上的 2-节点喂红——否则黑高立刻破坏
- moveRedLeft/moveRedRight：变色借侄 + 可能旋转——给删除腾出缓冲
- 双子节点：后继顶替（值换结构不动）→ 删除压力传给右子树
- fixup = 逆序三步（对照插入）：右红左黑左旋 → 双红右旋 → 变色
- **fixup 不压黑**——黑压由最外层 root 收尾（中途压黑破坏黑高与判断）

## 双黑四情形（LLRB 已压成 moveRed 两步）

- 兄弟有红侄 → 借过来（旋转一步到位）
- 兄弟无红侄 → 变色上移（双黑问题抛给父亲）
- LLRB 的 flip 统一处理：变色 → 检查红侄 → 旋转

## 画面读法

- 删除序列 [7, 1, 9]：三种现场（双子后继替换 / 叶删除 / 根删除）
- 每步删除后黄圈标定旋转/变色涉及的节点
- 终帧校验：根黑 ✓ 红红不相邻 ✓ 中序有序 ✓

## 怎么练

- 手推：删 1（叶）触发哪条 moveRed？（左子是 2-节点 → moveRedLeft）
- 思考：为什么 fixup 不能压黑？（中途压黑会让父级 moveRed 的 isRed 判断全错）
- 延伸：CLRS 版删除的四情形与 LLRB moveRed 的对应——同一数学的两种编排
