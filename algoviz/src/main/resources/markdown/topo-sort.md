# 拓扑排序

## 一句话

入度 0 → 没有前置依赖 → 可以安全执行——**依赖消解的过程就是拓扑排序**。

## 画面

- 绿色 = 已出圈（入结果），蓝 = 未出圈
- 队列/入度表实时显示在堆面板 `TopoState` 盒子里
- 黄圈 = 本步正在松弛的有向边（入度减 1）

## 不变量

- 入度 0 ⟺ 没有任何前置依赖 → 安全出圈
- 出圈后邻居入度各减 1——「我的所有前置都做完了」
- 结果不完整 = 图有环（入度永远 > 0）

## 🔗 应用

课程先修序列 · 构建依赖 · 任务调度 · 包管理器

## 怎么练

- 白纸推入度表逐帧变化，与画布绿色区对答案
