# 最近公共祖先（LCA）

## 一句话

p 和 q 分居某节点两侧 → 该节点就是 LCA；同侧 → 答案在那边。

## 递归三问

1. 空或命中 p/q → 直接返回该节点
2. 左右都非空 → 当前节点就是 LCA（分界点）
3. 只有一边非空 → 原样上传

## 不变量（意图层）

- 返回值含义：null = 两侧都没有；非空 = 找到 p/q 或 LCA
- LCA 的唯一判定条件：左右递归各返回一个非空

## 画面

绿区 = 命中的 p/q 节点；橙圈 = 当前递归位置；栈面板逐层压弹。

## 怎么练

- 白纸推 LCA(1,4)=3、LCA(1,9)=5——注意 5 是「分居两侧」的关键判定
