# 滑动窗口

## 一句话

hi 扩张遇重复，lo 收缩越过冲突位——**两根指针从不回头，O(n) 扫完所有候选窗口**。

## 画面

- 橙色 = lo（左边界），hi = 右边界
- 窗口 [lo,hi] 内永远无重复
- 黄圈 = 本步读入/移出的格子

## 不变量（意图层）

- 窗口 [lo,hi] 内永远无重复——hi 扩张遇冲突时 lo 收缩到冲突位之后
- O(n)：lo/hi 各最多 n 步，2n 次操作 vs 暴力 O(n²)

## 逐帧看

1. hi 右移读入新元素
2. 冲突？→ lo 逐个移出直到越过冲突元素
3. 记录窗口长度，与最佳对比

## 怎么练

- 白纸推 {2,1,3,1,4,4,2,5} 每一步的 lo/hi 位置和窗口内容
