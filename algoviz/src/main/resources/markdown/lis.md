# 最长递增子序列（LIS）

## 一句话

`dp[i] = 以 a[i] 结尾的 LIS 长度 = max(dp[j]+1, a[j]<a[i])`——每个元素问一遍前面的比它小的。

## 不变量

dp[i] 恒等于以 a[i] 结尾的最长递增链长度——转移只看 j<i 且 a[j]<a[i]。

## 演示数字

a = {3,1,4,1,5,9,2,6}：dp = {1,1,2,1,3,4,2,4} → LIS = 4（3,4,5,9 或 1,4,5,9…）

## O(n²) → O(n log n)

贪心+二进制的另一条路：维护 tails[]（各长度 LIS 的最小尾），
对每个元素二分替换——tails 严格递增，每次操作 O(log n)。

## 怎么练

- 白纸推本例 dp 表（8 个数）
- 思考：为什么"最小尾"策略不损失最优？（尾越小后续越容易接上——贪心的交换论证）
