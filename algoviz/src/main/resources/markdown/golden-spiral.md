# 黄金分割·斐波那契螺旋

## 一句话

相邻斐波那契数之比 → **φ = 1.6180339887…**；它同时是一条对数螺线的"生长率"。

## 不变量

- 比值摆动收敛：1, 2, 1.5, 1.667, 1.6, 1.625, …（两侧夹逼，误差每步 ×1/φ² ≈ 0.38）
- 对数螺线 r = φ^(2θ/π)：**每转 1/4 圈，半径 ×φ**——与斐波那契方块嵌套完全同构

## 画面读法

- 蓝色螺线逐段生长，橙色动点 = 当前螺旋末端
- 事件 = 每一步的比值分数（F(n+1)/F(n)）

## 藏在身边的 φ

- 黄金矩形切掉正方形，剩下还是黄金矩形——"对折永无止境"
- 向日葵籽排列黄金角 137.5°（= 360°/φ²）：最密的排布
- φ 的连分数全 1：[1;1,1,1,…]——"最难逼近"的数反而统治生长

## 怎么练

- 白纸列比值表到 F(12)/F(11)，误差 < 1e-4
- 思考：为什么摆动幅度每步缩小？（特征根 −1/φ 的模 < 1）
