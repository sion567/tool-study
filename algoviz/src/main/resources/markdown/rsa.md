# RSA 迷你版

## 一句话

公钥加密、私钥解密：`c = m^e mod n`，`m = c^d mod n`——**快速幂撑起整个互联网的信任**。

## 不变量

- e·d ≡ 1 (mod φ(n)) → 加解密互为逆运算（欧拉定理保证）
- n = p·q 公开，p·q 本身私藏

## 演示数字

```
p=3, q=11 → n=33, φ=20
公钥 (33, 3)，私钥 d=7
加密：m=4 → c = 4³ mod 33 = 64−33 = 31
解密：31⁷ mod 33 → 31²≡4, 31⁴≡16, 31⁷=16·4·31=1984 → 4
```

## 画面读法

- 堆面板三件套：公钥(@1) / 私钥(@2) / 消息(@3)
- 加解密中间值恒 < n²——这就是快速幂对 RSA 生死攸关的原因

## 安全性的本质

- 玩具版 n=33 秒破（试除）
- 真实 n=2048 位：分解 = 把一杯水还原成两条河——至今没人会
- 例外：量子计算机的 Shor 算法专杀大数分解（后量子密码已在路上）

## 怎么练

- 白纸算：m=5 的密文（5³=125 → 125−99=26 → c=26），再用 d 解回
- 思考：为什么 e 必须与 φ 互质？（否则不存在逆元 d）
