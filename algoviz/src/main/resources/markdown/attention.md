# Transformer 自注意力

## 一句话

每个词元用 q 查询所有 k，**softmax 打分后加权求和 v**——"关注谁、关注多少"由数据自己算出来。

## 不变量

```
score(q,k) = q·k / √d        ← ÷√d 防 softmax 饱和
weights = softmax(scores)
output = Σ weights · v
```

## 演示数字

词元 猫/坐/垫，嵌入 d=2（W=I 简化）：
- 猫 → 权重 [0.40, 0.20, 0.40]
- 输出[猫] = 0.40·猫 + 0.20·坐 + 0.40·垫——"猫"吸收了上下文

## 三大配套

- **多头**：并行多组 Q/K/V，各看各的角度
- **位置编码**：注意力本身无序——把位置信息注入嵌入
- **残差 + FFN**：每层 = 注意力 + 前馈 + 残差

## 为什么统治 AI

RNN 逐步滚动 → 注意力全并行（GPU 友好）；任意两词一步直达（长程依赖免费）。
GPT/BERT/ViT 全是它的变体——2017 年《Attention Is All You Need》的分水岭。

## 怎么练

- 手算坐→垫的得分（0·1+1·1 = 1，÷√2 = 0.707）
- 思考：没有 ÷√d 会怎样？（d 大时得分巨大 → softmax 饱和 → 梯度消失）
