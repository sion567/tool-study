# BatchNorm 归一化

## 一句话

x̂ = (x−μ)/√(σ²+ε) 把每层激活**拉回正态**——γ·x̂+β 的缩放平移可学习。

## 不变量

- 内部协变量偏移：上一层参数一动，下一层输入分布就漂——训练像踩独轮车
- 标准化：均值归 0 方差归 1——离群值 9 也被拉回正常刻度
- γ/β 可学习："要多标准、偏多少"网络自己定——归一化不是硬约束
- 训练/推理差异：推理用训练期滑动平均 μ/σ——单个样本也能算

## 画面读法

- 三行同屏：原值（含离群 9）/ 标准化 x̂ / γβ 后——第三行的分布形状由 γβ 决定
- 黄圈 = 本步标准化计算涉及的格子

## 与 ResNet 的双子星

- 残差解决**能训多深**、BN 解决**训得多快**——2015 年双双落地
- BN 让 lr 可以更大：收敛快一个数量级

## 怎么练

- 手算：batch [1,2,3,9] 的 μ=3.75、σ²=9.19——x₄ 的 x̂ = (9−3.75)/√9.19 ≈ 1.73
- 🎯 预测：猜标准化行的值——本质是"离均值几个标准差"
- 思考：ε=1e-5 防什么？（方差为 0 的退化 batch——除零保护）
