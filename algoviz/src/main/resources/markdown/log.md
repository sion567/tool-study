# 对数·乘法变加法

## 一句话

对数是指数的逆运算——**把乘法压成加法（计算尺）、把指数压成步数（二分砍半）**。

## 不变量

- 砍半 k 次覆盖 2ᵏ 个候选：⌈log₂1000⌉=10 次猜中、2²⁰≈10⁶——指数爆炸的另一面是对数收敛
- log_b(xy) = log_b x + log_b y：乘法→加法，除法→减法——计算尺 400 年的心算代偿
- 换底公式 log_b a = lg a / lg b：底换成谁都行，只差常数倍（bit 用底 2、数学用 e）
- 复杂度阶梯 n=10⁶：O(1)=1 / O(log n)=20 / O(n)=10⁶ / O(n·log n)=2×10⁷ / O(n²)=10¹²

## 画面读法

- 砍半序列格：1000→500→250→…→1，黄格 = 已砍过——每次猜中点区间折半
- 计算尺格：上行=数（2,3,6），下行=lg（加下行 = 乘上行）
- 复杂度阶梯格：n 翻倍时 O(log n) 列只 +1——二分/BST/快速幂敢称"极快"的底座

## 历史线

- 1614 纳皮尔发表对数表——" Purpose：把乘法变成加法"，天文学家第谷靠它省了半辈子心算
- 计算尺（1622~1970s）：工程师上过月球的随身计算机，原理就是 log 刻度
- 1971 之后芯片接管——但 log 的思想进了二分搜索、FFT、信息熵（bit=log₂）、里氏震级（+1 能量×32）

## 怎么练

- 🎲 换上限：N=100/1000/10⁶，看砍半次数 7/10/20——每 +1 次砍半覆盖翻倍
- 手算：lg4=lg2+lg2=0.60206 ✓；log₂100 = 2/0.30103 ≈ 6.64
- 思考：为什么折纸 42 次能到月球？（0.1mm×2⁴²≈44 万 km > 38.4 万——指数的暴力）
