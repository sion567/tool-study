# 组合构造·骑士巡游

## 一句话

马走"日"字踏遍 8×8 每格恰一次——**Warnsdorff 启发式**：永远走出度最小的格，单步贪心近乎全胜。

## 不变量

- 马的 8 个候选位（走"日"字），每格恰访一次 = **哈密顿路径**
- Warnsdorff 法则：优先走进「后续出路最少」的格子——先把死角消耗掉
- 它**不保证成功**（是启发式不是定理），但 8×8 实战成功率极高

## 画面读法

- 8×8 网格：格值 = 到访序号 1..64，黄圈 = 马当前位置，绿 = 已走过的格
- 堆里「当前出度」：每步的候选余量——后期出度骤减，死角争夺战
- 🎯 点选预测：暂停猜下一帧马落在哪格——你得亲自算每个候选的出度，这就是 Warnsdorff 本人在做的事

## 启发式 vs 回溯

- N 皇后用回溯：撤销保正确，代价是指数时间
- 骑士巡游用 Warnsdorff：眼光免撤销，代价是失去完备性
- **8×8 巡游路线 ≈ 2.6×10¹³ 条**：构造出一条，比数清所有条容易得多

## 怎么练

- 🎲 换四角起点再走一遍——角是出度最低的格，最适合「先消耗」
- 手算：角落格出度 2、中心格出度 8——为什么 Warnsdorff 天然偏爱往角走？
- 思考：如果贪心走「出度最大」会怎样？（快速走进开阔地 → 后期满盘死角 → 几乎必败）
