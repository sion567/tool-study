# CNN 卷积与池化

## 一句话

核在输入上**滑动做点积**——一个 3×3 核共享全图，把"边缘"这种概念变成一个数字。

## 不变量

- 输出尺寸 = 输入 − 核 + 1（valid）
- 参数共享：16 个输出共用 9 个权重（全连接要 576 个）
- 池化：2×2 取最大 → 尺寸减半、平移容忍

## 演示数字

输入左半 1 / 右半 5（垂直边缘），核 [[−1,0,1]×3]：
- 窗口在平坦区：左右相等 → 0
- 窗口跨边界：+12 → 一根亮线标记了边缘位置

## 层层堆叠

卷积(提特征) → 池化(压缩) → 卷积 → 池化 → … → 全连接(分类)。
从像素到语义：浅层认边缘，中层认纹理，深层认物体。

## 怎么练

- 白纸算一个窗口的点积
- 思考：核改成 [[1,1,1]×3]（均值核）输出会怎样？（模糊——不是边缘）
