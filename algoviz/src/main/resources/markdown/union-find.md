# 并查集

## 一句话

用一棵树表示一个集合：Find 查根（同根=同集合），Union 合并两棵树。

## 画面

- 有向边 = parent 指针（子→父），绿色 = 根节点
- 路径压缩帧：子节点直接指向根——树越走越扁

## 不变量

- Find 返回同一个根 ⟺ 同一集合
- 路径压缩让树越走越扁 → 查找接近 O(1)（α(n) 反阿克曼函数）

## 🔗 应用

Kruskal 判环 · 连通分量 · 社交网络朋友圈 · 最小生成树

## 怎么练

- 🎯 白纸推 union(A,B) → union(C,D) → union(B,D) 后 parent 数组的变化
