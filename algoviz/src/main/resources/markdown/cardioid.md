# 笛卡尔·心形线

## 一句话

极坐标一行 `r = a(1 − cosθ)`，落到笛卡尔坐标系是一颗心——**解析几何 = 几何 ↔ 代数的双向翻译**。

## 不变量

```
极坐标 (r, θ)  →  直角坐标 (x, y)
x = r·cosθ
y = r·sinθ
```

每转一个 θ：算 r → 换算 (x,y) → 落点连线。48 个点连出一颗心。

## 画面读法

- 橙色动点从原点出发（θ=0 时 r=0，尖点）
- 逆时针转一圈：上瓣 → 左半圆（θ=π 时 r=2，最远）→ 下瓣 → 回原点
- 橙色细线 = 极径（原点到动点）——极坐标的"r"在笛卡尔坐标系里的样子

## 两种坐标系的分工

| | 笛卡尔 (x,y) | 极坐标 (r,θ) |
|---|---|---|
| 擅长 | 直线、平移对称 | 旋转对称、绕原点的曲线 |
| 心形线 | 参数方程两行，丑 | **一行** |

## 趣闻与正名

"笛卡尔用 r=a(1−cosθ) 向公主表白"的数学情书故事广为流传——**是后人编的**。
真实的笛卡尔贡献：1637 年《几何学》创立解析几何，让几何题可以"算"出来。

## 怎么练

- 白纸算 4 个点：θ=0°, 90°, 180°, 270° 的 (r, x, y)（r=0, 1, 2, 1）
- 变形：cosθ 换 sinθ（心转向右）；调参数 a（心变大）
