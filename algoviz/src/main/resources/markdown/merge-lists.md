# 合并有序链表

## 一句话

双指针比小，谁小谁接——O(n+m) 单趟扫完，没有嵌套循环。

## 画面

- 上方数组 = A 链 + B 链（全部元素），橙色 = A 的当前头，青色 = B 的当前头
- COMPARE 帧 = 双指针比大小
- SET 帧 = 小的那个接到 result

## 不变量

- result 始终有序——每步只从两个头中选较小的接上去
- 虚拟头节点 dummy 技巧：免去「第一个节点」特判

## 对比归并排序

合并有序链表的 merge 步骤 = 归并排序的治阶段——**一模一样的双指针比小逻辑**，只是数据源从子数组换成子链表。

## 怎么练

- 白纸推 {1,3,5} + {2,4,6} 合并的每一步
- 思考：为什么用 dummy 节点就不用特判「第一个接谁」
