# 哈希·SHA-256

## 一句话

与 SM3 同构的 64 轮压缩——**Ch/Maj 布尔函数 + Σ/σ 双旋转**；常数不靠背：素数根小数部分程序生成。

## 不变量

- H/K 常数 = 前 8/64 个素数的**平方根/立方根小数部分**×2³²——"无先验结构"的数学出处
- 轮函数：T1 = h + Σ1(e) + Ch(e,f,g) + K[j] + W[j]；T2 = Σ0(a) + Maj(a,b,c)
- Ch(X,Y,Z) = (X∧Y)⊕(¬X∧Z)："Y 说了算，除非 X 否决"；Maj = 按位多数表决
- 收尾 **H += 轮转终态（模加）**——对照 SM3 的异或回写：同构算法的细节分野

## 画面读法

- 上网格 = 分组字节（绿 = 填充与长度区）
- 下网格 = H0..H7（每帧 8 轮，模加回写）
- NIST 示例：SHA-256("abc") = ba7816bf 8f01cfea … f20015ad

## 与 SM3 对照

| | SHA-256 | SM3 |
|---|---|---|
| 布尔函数 | Ch/Maj | FF/GG（同语义） |
| 置换 | Σ0/Σ1 + σ0/σ1 | P0/P1 |
| 回写 | 模加 | 异或 |
| 常数 | 素数根程序生成 | T 表固定值 |

- 🎲 换消息："哈希对照"是 UTF-8 多字节——观察填充
- 手算：K[0] = cbrt(2) 的小数部分 0.259921×2³² = 428a2f98——用计算器验证
- 思考：为什么用素数根做常数？（"无人能构造出规律"——后门疑虑的数学回应）
