# 相交链表

## 一句话

走完自己的走对方的——总步数相等时双指针必然同步，交点自然出现。

## 画面

上排 = A 链（1,2,3,7,8,9），下排 = B 链（4,5,7,8,9），公共段 7,8,9 重叠。

## 不变量

- pA 走 a+c 步切到 B，pB 走 b+c 步切到 A → 总步数 = a+b+c（相同）
- 交点前两条链元素不同，交点后完全相同 → 同步前进时首次相等就是交点

## 数学原理

pA 走的路 = a + c + b（自己的独有段 + 公共段 + 对方的独有段）
pB 走的路 = b + c + a（自己的独有段 + 公共段 + 对方的独有段）
**两条路长度相同** → 一定同步到达交点或同时到尾。

## 怎么练

- 白纸画两条链，标出指针切换点——理解为什么切到对方后一定同步
