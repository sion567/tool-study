# 布隆过滤器

## 一句话

多个 hash 函数将元素映射到 bit 数组的多个位置——**有 0 位 → 一定不存在，全 1 → 可能存在（有误判）**。

## 不变量

- **无假阴性**：添加过的元素查询一定返回「可能存在」
- **有假阳性**：不同元素的 hash 位可能碰撞 → 未添加的元素也可能返回「可能存在」
- 只查不加，不会有假阴性——这就是为什么缓存系统用它挡无效请求

## 画面

- BitSet 格子，hash1 和 hash2 两条线的落点逐帧高亮
- 已置 1 的格子在后续查询中变绿

## 怎么练

- 🎯 预测页：添加 apple 后查询 cherry——猜「可能存在」还是「一定不存在」
- 思考：为什么布隆过滤器没有假阴性？（答：每个添加过的元素的 hash 位都已置 1）
