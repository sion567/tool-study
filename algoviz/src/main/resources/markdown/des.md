# 对称·DES（1977）

## 一句话

64 位块 16 轮 Feistel——**解密 = 子密钥倒序重放同一轮函数**，f 不要求可逆（Feistel 结构的数学馈赠）。

## 不变量

- L(i)=R(i-1)、R(i)=L(i-1)⊕f(R,K)：每轮只动一半，另一半原样递给下一轮
- f = P(S(E(R)⊕K))：E 扩展 32→48 → ⊕子密钥 → S1-S8 六进四出（唯一非线性）→ P 置换
- 密钥 64 位但每字节第 8 位是奇偶校验——**有效密钥 56 位**（PC1 直接弃掉 8 位）
- S 盒行 = 首末两位、列 = 中间 4 位——8 个盒子并行，32 位进 32 位出

## 画面读法

- L/R 状态格（hex）：每帧 2 轮全字更新，最终帧 L16=43423234、R16=0a4cd995
- 经典例（Grabbe 教程）：key=133457799BBCDFF1、plain=0123456789ABCDEF → 密文 **85e813540f0ab405**
- 黄圈 = 本帧完成的两轮——扩散逐轮翻倍，雪崩效应到第 5 轮已"面目全非"

## 历史线（这才是 DES 的主戏）

- 1975 NBS 公开征集 → IBM Lucifer 方案改造 → **1977 FIPS 46 成为联邦标准**
- NSA 当年的手笔：S 盒设计准则保密 20 年——后来证明是防差分分析（Biham-Shamir 1990 公开该攻击时，DES 早已"打过疫苗"）
- **1998 EFF Deep Crack：25 万美元机器 22 小时暴力破解**——56 位密钥的死刑判决书
- 3DES 过渡（K1→K2→K1 三重加密，112 位有效）→ 2001 AES 接棒 → 至今仍在银行老系统、EMV 卡里服役

## 与 SM4 的对照

- SM4 = 32 轮不均衡 Feistel（每轮动 1/4 状态）；DES = 16 轮均衡 Feistel（每轮动一半）
- SM4 的 S 盒是黑盒查表，DES 的 S 盒是"设计过的黑盒"——**S 盒之母**：AES/SM4 的非线性层设计思想都从它出发
- 同一收尾式：子密钥倒序重放——Feistel 一脉相承（DES/SM4/Blowfish/Twofish）

## 怎么练

- 🎲 换密钥：子密钥全变脸，但结构不动——扩散的活儿全在 S 盒 + P 里
- 手算第 1 轮：f(R0,K1)=234aa9bb，R1 = CC00CCFF⊕234AA9BB = EF4A6544——对照画面逐位对
- 思考：为什么 16 轮刚好够？（差分/线性分析各需 2⁵⁵/2⁴³ 工作量——16 轮是 1977 年算力下的甜蜜点）
