# 堆排序

## 一句话

先建大顶堆（父 ≥ 孩子），再反复「堆顶换到末尾 + 重新堆化」——**原地 O(n log n)，最坏也稳**。

## 生活故事

擂台赛：最强者站上台顶（堆顶），把他拉下来发奖（放到数组尾部），剩下的选手重新选出一个最强的顶上去——**每次操作后全场最强永远在台顶**。

## 不变量（意图层）

- **堆化后 a[i] ≥ a[2i+1] 且 a[i] ≥ a[2i+2]**——堆顶永远是当前最大值
- 数组的父子关系：i 的孩子 = 2i+1 和 2i+2——不需要真的建树，下标就是树

## 画面怎么读

- 右面板：`heapSize` 逐帧缩小（每取一次堆顶减 1）
- 绿区从右往左生长：已归位的尾部
- 黄圈 = 本步交换的两个格子（下沉路径）

## 两阶段

1. **建堆 O(n)**：从最后一个非叶子节点（n/2-1）开始，自底向上每个节点下沉——叶子天然合法
2. **排序 O(n log n)**：n-1 次「堆顶换尾 + 堆缩小 + siftDown」

## 对比其他排序

- 快排：平均快但有 O(n²) 退化 / 堆排序最坏也是 O(n log n)
- 归并：要 O(n) 辅助数组 / 堆排序 O(1) 原地
- 缺点：缓存不友好（跳跃访问）、不稳定

## 怎么练

- 🎯 预测页：siftDown 帧问「哪两个格子会交换」——看 2i+1/2i+2 的下标计算
- 白纸推 {5,2,9,1,5} 建堆后数组形态，再推第一次堆顶换尾
