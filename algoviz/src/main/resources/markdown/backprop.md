# 反向传播逐层演算

## 一句话

链式法则在计算图上的动态规划——**每层的梯度 = 后一层梯度 × 本层局部导数**，一次反向遍历算完全部。

## 不变量

- 前向：h = σ(w1·x+b1)、y = w2·h、L = (y−t)²
- 反向链：∂L/∂y = 2(y−t) → ∂L/∂w2 = ∂L/∂y·h → ∂L/∂h = ∂L/∂y·w2 → ∂L/∂w1 = ∂L/∂h·h(1−h)·x
- sigmoid 局部导数 h(1−h) ≤ 0.25——乘得越多越小：**深层的梯度消失**现场
- 更新 w ← w − lr·∂L/∂w：一步就有可见的损失下降

## 画面读法

- 上网格 = 前向值（黄圈 = 损失与输出）
- 下网格 = 梯度表逐格填充——每个数字都是链式法则现场算出来的
- 二次前向帧：L 从 %.4f 明显下降——千万个这样的小步就是"训练"

## 本局演算

- x=1.0、t=1.0、lr=0.5、w1=[0.5,−0.3]、w2=[0.8,−0.6]
- ∂L/∂y = 2(y−t)——"错得越多推得越狠"
- 一步更新后损失可见下降

## 怎么练

- 手算：照着网格把 ∂L/∂w1 的两个数字自己算一遍——对照画面
- 思考：为什么 sigmoid 网络深层梯度消失？（每层乘 ≤0.25，10 层就 ×10⁻⁶）
- 延伸：ReLU 局部导数恒 1——深层网络能训起来的一半功劳是它
