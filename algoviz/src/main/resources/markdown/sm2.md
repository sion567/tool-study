# 非对称·SM2 与椭圆曲线

## 一句话

点加 = 弦线交第三点后取反——**mod 17 的教学曲线是 SM2 的沙盘**：几何在实数上练，算术在有限域上算。

## 不变量

- 点加公式：λ=(y₂−y₁)/(x₂−x₁)（倍点 λ=(3x₁²+a)/2y₁）、x₃=λ²−x₁−x₂、y₃=λ(x₁−x₃)−y₁
- "除法" = 乘模逆元（扩展欧几里得的功劳，见 olympiad.crt）
- mod 17 曲线 y²=x³+2x+2 的点构成 **19 阶循环群**：从 G=(6,3) 出发加 18 步遍历全部仿射点，第 19 步回 O
- 群阶素数 → 每个非 O 点都是生成元——教学曲线是"小而完整"的群

## 画面读法

- 蓝线 = 实数曲线形状（弦切几何的直观），绿点 = mod 17 的全部整数解
- 标量乘帧：弦线连接 kG 与 G → 落到 (k+1)G——椭圆曲线版的"快速幂"
- 8G 之后就"看不见"了？点在 0..17 间乱跳——有限域没有"连续曲线"的美感，只有代数

## SM2 真实参数

- 256 位素数曲线 p、基点 G、群阶 n≈2²⁵⁶——把 (6,3) 换成 78 位十六进制就是工业曲线
- 私钥 k 是"步数"，公钥 P=kG 是"终点"：正算一毫秒，倒算（离散对数）到宇宙热寂
- 签名 = 随机数 r 与 k 的组合运算；验签 = 公钥反算——零知识地证明"我有 k"

## 怎么练

- 手算：2G 的 λ = (3·36+2)/6 = 110/6 ≡ 8×3 = 7 (mod 17)——对照画面
- 思考：为什么"曲线"在 mod 世界里不是曲线？（离散点集——但每一点仍严格满足方程）
- 延伸：RSA 靠分解大数难，SM2 靠曲线离散对数难——同安全目标的两条数学路
