# 大数竖式运算

## 一句话

竖式 = 位值制的逐位传播——**加法进位链从低位涌向高位，乘法部分积错位累加**（朴素 O(n²)）。

## 不变量

- 加法：满 10 进 1——进位链是唯一跨位的依赖，从个位涌向高位
- 乘法：a 的每位 × b = 一个部分积，按位权错位累加——6 位乘 6 位 = 6 行部分积
- 本局：123456+654321 = **777777**；123456×654321 = **80779853376**
- 朴素竖式 O(n²)；Karatsuba 分治 O(n^1.585)——同一问题的暴力与聪明（见 math.karatsuba）

## 画面读法

- 上网格 = 加法竖式：进位/a/b/和 四行，黄列 = 当前位（进位链可视化）
- 下网格 = 乘法部分积：6 行右对齐错位——位权决定错位层数
- 🎯 点选预测：猜下一位的和与进位

## 计算机里的大数

- RSA 的 2048 位乘法 = 竖式思想 + 基数从 10 换成 2³²（每"位"容纳 9 位十进制）
- Java 的 BigInteger、Python 的原生 int——底层全是这套位传播

## 怎么练

- 🎯 预测：暂停加法中途，猜下一位的进位
- 白纸算：777777 每一位的进位链自己推一遍
- 思考：为什么乘法是 O(n²) 而加法只有 O(n)？（部分积行数 = n——每行还要 O(n) 累加）
