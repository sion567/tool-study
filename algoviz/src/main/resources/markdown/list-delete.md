# 删除节点

## 一句话

单链表删除 = 前驱跳过目标：`prev.next ← curr.next`，改道就完了。

## 不变量

删除改的是**前驱**的 next，不是被删节点自己——所以 prev 必须提前一站。
被删节点从此不在链上，但它还躺在堆里，等 GC 收走。

## 三个坑

1. **删头节点没有 prev** → 经典解法：dummy 哨兵（`dummy.next = head`，
   删完返回 `dummy.next`），特判直接消失
2. **prev/curr 同步走** → 单链表回不去，curr 走的时候 prev 必须跟着挪
3. **找到 ≠ 删掉** → 命中后那一行改道才是删除本体，前面全是找路

## 单链 vs 双链

| | 单链表 | 双链表 |
|---|---|---|
| 删已知节点 | O(n)——先走一遍找 prev | **O(1)**——`del.prev` 现成 |
| 指针开销 | 1 根 next | 2 根 next + prev |

LRU 缓存淘汰为什么用双链表？——O(1) 删任意节点，答案就写在上面这行。

## 画面读法

- prev（绿）/ curr（橙）标签沿链走位
- 命中那一刻的改道箭是黄圈——它就是"删除"这两个字的全部
- 被删节点与链脱钩（没有箭再指向它）

## 怎么练

- 白纸默写：哨兵 + 双指针走链 + 改道，共 7 行
- 变形：删除所有等于 target 的节点（循环里 prev 不能动！）
