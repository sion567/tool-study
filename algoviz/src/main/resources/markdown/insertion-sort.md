# 插入排序

## 一句话

像摸扑克牌：每摸一张，在已排好的手牌里从右往左找位置插进去。

## 生活故事

就是摸牌本身：手上的牌始终有序，新牌抽出来，从最大的那张开始比，比它大的右移腾位，挪不动了就插进去。**"基本有序的数据"它飞快**（接近 O(n)）。

## 不变量（意图层）

- 手牌区 **[0..i-1] 始终有序** → `key` 抽出后原位置是「坑」，右移就是在搬坑
- 移位的不是交换：`a[j+1] = a[j]` 单向搬，所以搬的次数是交换的三分之一
- while 的两种停法：`a[j] ≤ key`（找到位）或 `j = -1`（比谁都小，插最前）——**边界考这两处**

## 什么时候用 / 代价

- O(n²) 最坏，但**基本有序时 O(n)** → 生产里它活在快排/ TimothySort 内部（小区间用插入）
- 稳定；数据近乎有序时是最快的简单排序

## 怎么练（健身房，蓝图 §2.5-C）
