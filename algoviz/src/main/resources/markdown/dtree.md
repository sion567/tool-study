# 决策树·信息增益

## 一句话

Gain = H(S) − Σ (|Sv|/|S|)·H(Sv)——**增益最大的特征先分裂**（ID3 的贪心）。

## 不变量

- 熵 H(S) = −Σ p·log₂p：4 是 4 否时最乱（1.0）；全一类时为 0
- 天候增益 0.311（阴天子集纯）> 风力 0.049——**"天候"当选根**
- 每个特征问一遍"分组后还剩多少混乱"——增益 = 省下的疑问
- ID3 → C4.5（增益率防偏袒）→ CART（基尼系数）→ 随机森林（多树投票）

## 画面读法

- 上网格 = 数据表（黄列 = 候选根特征）
- 下网格 = 熵/增益对照：增益最大者当选根（黄圈标定）
- 🎯 点选预测：猜哪个特征增益更大

## 本局演算

- 天候：晴(1是1否) 阴(2是0否，纯!) 雨(1是2否) → 条件熵 0.689 → **增益 0.311**
- 风力：弱(3是2否) 强(1是2否) → 条件熵 0.951 → 增益 0.049

## 怎么练

- 手算：阴天组全"是" → 子熵 0——它贡献了最大的一块增益
- 思考：为什么 ID3 偏袒取值多的特征？（分得越碎子集越纯——增益率 C4.5 的修正）
- 延伸：决策树是"可解释 ML"的门面——每个 if 都能讲出人话
