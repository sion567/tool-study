# 斐波那契 × 矩阵幂

## 一句话

`M = [[1,1],[1,0]]` 的 Mⁿ 右上角就是 F(n)——**快速幂的矩阵版，O(log n) 直达**。

## 不变量

```
Mⁿ = [[F(n+1), F(n)], [F(n), F(n−1)]]
```

矩阵乘法天然生成斐波那契递推——平方一次指数翻倍。

## 三种算法对比（F(32)）

| 算法 | 步数 |
|---|---|
| 朴素递归 | ~250 万次调用 |
| 线性递推 | 31 次加法 |
| **矩阵幂** | **5 次矩阵乘法** |

n=2¹⁰⁰ 时：递推 10²⁰ 步（不可能），矩阵幂 100 步。

## 线性递推的通解引擎

任何 k 阶线性递推（Lucas、Tribonacci、马尔可夫链）都能写成 k×k 矩阵幂 → O(k³ log n)。

## 与黄金螺旋的呼应

矩阵的特征方程 x²=x+1 → 特征根 φ 与 −1/φ——**就是黄金螺旋那一课的比值收敛**。
