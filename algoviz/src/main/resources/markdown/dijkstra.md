# Dijkstra

## 一句话

从起点起涟漪：**每次挑当前最近的未定点出圈，用它松弛邻居**——出圈的瞬间，它的最短路就定死了。

## 生活故事

水波扩散：石头（起点）落水，涟漪一圈圈往外推。**波前最先到达的点，走的必然是最短路**（边权非负，绕路只会更慢）——这就是"出圈即定死"的物理直觉。

## 不变量（意图层）

- **已出圈节点的距离永远不再变**——整个算法的正确性全押在这一句上
- 松弛：`dist[u] + w < dist[v]` 才更新——"绕过去更近才改主意"
- 贪心挑最小：未定点里 dist 最小的 u，任何绕路（经过其他未定点）都只会更长 → 它可以安全出圈（这也是为什么负权边会翻车，TraceAsserts 里专门拦了负权边）

## 逐行看（对着代码高亮）

1. `dist[src] = 0`：起点入圈
2. `u = 未定点中 dist 最小的`：贪心挑圆心
3. `settled[u] = true`：出圈定死（绿）
4. `if (dist[u] + w < dist[v])`：松弛判断，黄边 = 正在比较的边
5. `dist[v] = dist[u] + w`：距离表跳动（D 会从 10 被压到 8——"绕远点的路反而更短"）

## 怎么练（健身房，蓝图 §2.5-C）

1. 🎯 预测页：「哪些节点会变？」——松弛判断帧答案是"没节点变"（只是比较），松弛帧才是距离变
2. 盯 D 的距离：10 → 8 的那一跳，问自己为什么 B 出圈后 D 变矮了
3. 白纸跑一遍全表（A 起点），和最终 d 值对答案：A0 B3 C2 D8 E10 F13
