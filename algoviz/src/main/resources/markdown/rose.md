# 玫瑰线画廊

## 一句话

`r = cos(kθ)`：**k 奇 = k 瓣，k 偶 = 2k 瓣**——一个参数决定一朵花。

## 不变量

- |r| ≤ 1：花瓣长短 = 1
- 负半径 = 翻到对面方向（cos 出负值时点落在原点对称侧）——偶数 k 靠它翻出双倍花瓣
- k 奇数：θ 转 π 就闭合；k 偶数：要转满 2π

## 三幅展品

| k | 花瓣 | 备注 |
|---|---|---|
| 2 | 四叶 | 两叶重叠成四叶 |
| 3 | 三叶 | 旋转对称 120° |
| 5 | 五叶 | 与五边形同宗 |

## 一码多花

同一个采样循环（θ 步进 → 算 r → 落点连线）画遍所有玫瑰线——
换 sin(kθ) 花瓣转 45°/30°（相位旋转），无需重算。

## 怎么练

- 白纸算 k=2 时 θ=22.5° 的点（r=cos45°≈0.707，在第一、三象限各一个）
- 变形：r = 1 + cosθ（心形线的亲戚——'蜗线'）
