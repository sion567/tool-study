# 红黑树插入

## 一句话

BST + 五条颜色规则：**黑高恒定 + 红不相邻** → 树高 ≤ 2log(n+1)——插入删除最坏 O(log n)。

## 五条规则

1. 节点非红即黑
2. 根是黑
3. 叶（null）是黑
4. **红节点的孩子必黑**（红不相邻）
5. 任一节点到其后代叶的黑节点数相同（黑高）

## 插入的修复三招

新节点染红（不破黑高）→ 若父红则违规，依次：
1. **叔叔红**：父与叔变黑、祖变红，向上递归
2. **叔叔黑 + 三角形**：旋转成直线
3. **叔叔黑 + 直线**：祖变色 + 旋转

## 与 AVL 的取舍

| | AVL | 红黑树 |
|---|---|---|
| 平衡严格度 | 更严（高差≤1） | 较松 |
| 查找 | 略快 | 略慢 |
| 插入/删除 | 旋转多 | 旋转少（≤2/≤3） |

Java TreeMap/HashMap 树化桶用红黑树——写多场景的工程选择。
