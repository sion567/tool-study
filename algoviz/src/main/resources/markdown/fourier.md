# 傅里叶变换

## 一句话

任何信号 = 不同频率正弦波的叠加；DFT 把它**拆回频率成分**——峰在哪，那个频率就在信号里。

## 不变量

```
X[k] = Σ x[n]·e^(−i2πkn/N)
|X[k]| 峰 → 频率 k 的成分存在；2|X[k]|/N = 该成分的幅度
```

## 演示数字

```
x(t) = sin(3ωt) + 0.5·sin(7ωt)
→ 频谱：频率 3 处高度 1.0、频率 7 处高度 0.5，其余 ≈ 0
→ 两个峰单独"拎"出来 = 原来的两条正弦
```

## 为什么革命

- 时域里纠缠的波形，频域里一排柱子——**换坐标系看问题**
- MP3/JPEG 压缩：扔掉感知不敏感的频率分量
- FFT：Cooley-Tukey 1965，O(n²) → O(n log n)
