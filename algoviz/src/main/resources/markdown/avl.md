# AVL 树旋转

## 一句话

BST + 每节点维护高度：平衡因子（左高−右高）**|bf|>1 就旋转**——四种失衡四种转法。

## 四种失衡与转法

| 插入位置 | 失衡型 | 转法 |
|---|---|---|
| 左孩子的左 | LL | 右旋 |
| 右孩子的右 | RR | 左旋 |
| 左孩子的右 | LR | 先左旋孩子，再右旋自己 |
| 右孩子的左 | RL | 先右旋孩子，再左旋自己 |

口诀：**哪边高往反方向转；之字形先捋直**。

## 演示数字

插 {10,20,30,40,50,25}：
- 30 触发 RR → 左旋（20 沉底）
- 50 触发 RR → 左旋（30 沉底）
- 25 触发 RL → 先右旋 40 再左旋 30 → **根 = 30**

## 旋转的三个不变量

1. 中序序列不变（还是那棵 BST）
2. 子树高度减一（失衡消除）
3. 只动三个指针（O(1)）

## 怎么练

- 白纸画 30-RR 与 25-RL 两次旋转的指针变化
- 思考：为什么旋转后必须回溯更新高度？（祖先的平衡因子也可能被牵连）
