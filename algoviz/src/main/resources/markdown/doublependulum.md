# 力学·双摆混沌

## 一句话

方程完全确定，命运完全不可预测——**混沌 = 确定性规律 + 初值误差指数放大**。

## 不变量

- 同一初值必得同一结局（方程没有掷骰子）
- 初值差 10⁻³ rad 的幽灵双摆，12 秒内分离三个数量级——**蝴蝶效应的力学原版**
- 能量守恒：RK4 的漂移 ≈ 10⁻⁷——混沌不是模拟误差，是方程本身的性格

## 画面读法

- 橙臂橙锤 = 主双摆（θ₁=115° 大角度释放），蓝线 = 主摆锤走过的乱麻轨迹
- 灰虚点 = 幽灵摆锤（初值只差 0.001）——前几秒跟主摆几乎重合
- 堆里「放大倍数」：从 ×1 涨到 ×1000+，倒计时开始后就再也拦不住

## 为什么是双摆

- 单摆小角度可以线性化 → 简谐运动 → 可以写在纸上
- 双摆多了第二个约束，方程彻底非线性 → **没有初等解**，只能数值积分
- 大角度不是细节：混沌就藏在 sinθ 里那点非线性

## RK4 是什么

- 每步在半程多点采样斜率、加权平均——四阶精度：dt 减半，误差缩 16 倍
- 即便如此，混沌系统的初值误差照样指数放大：**能算 ≠ 能预测**

## 怎么练

- 白纸算：想让预测翻倍准，步长要缩多少？（四阶 → 16 倍精度，但初值误差照样吃掉它）
- 思考：天气预报为什么 15 天是硬极限？（不是算力，是误差放大把信息吃光）
- 延伸：三体问题无通用闭式解（庞加莱）——数值积分是唯一的望远镜
