# 大数乘法（Karatsuba）

## 一句话

x·y 拆两半，4 次子乘法变 3 次——恒等式 `ad+bc = (a+b)(c+d) − ac − bd` 是全部魔法。

## 不变量

```
x = a·10^m + b,  y = c·10^m + d

朴素：  x·y = ac·10^2m + (ad+bc)·10^m + bd      ← 4 次乘法
Karatsuba：ad+bc = (a+b)(c+d) − ac − bd         ← 3 次乘法 + 两次减法
```

## 为什么 4 → 3 这么厉害

递归乘法次数是 4^log n = n²（朴素）vs 3^log n = **n^1.585**。

| 位数 | 朴素 n² | Karatsuba | 提速 |
|---|---|---|---|
| 1024 | 100 万次 | 6.6 万次 | ~15× |
| 4096 | 1600 万 | 42 万 | ~38× |

位数越大差距越恐怖——密码学动辄 2048/4096 位大数。

## 代价与边界

- 代价：拆分/合并的加减与拷贝 O(n)——位数小时反而比朴素慢
- 所以工程实现是**混合策略**：位数 < 阈值用朴素乘，超过才切 Karatsuba
  （Java BigInteger 的阈值是 80 个 int）
- 更大再切 Toom-Cook（3 段）、FFT（O(n log n)）

## 画面读法

- 拆分网格：a/b/c/d 四个小数
- 三次乘法网格：P1=ac、P2=bd、P3=(a+b)(c+d) 逐个点亮
- 合并网格：中间项 = P3−P1−P2，位权 10^4 / 10^2 / 10^0 拼回
