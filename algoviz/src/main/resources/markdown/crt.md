# 数论·扩展欧几里得与 CRT

## 一句话

exGCD 算出「模世界的除法」（逆元），CRT 用它把两个同余方程合并成唯一解——**物不知数，四千年前的中国算法**。

## 不变量

- Bézout 恒等式：m·s + n·t = gcd(m,n) 全程成立——迭代只是换 (s,t) 的表示
- gcd(m,n)=1 时 s 就是 m mod n 的**逆元**：「1/m」在模世界有了身份证
- CRT：模数互质 → 同余组**恰有一解**（mod mn）——两个余数像经纬度钉死一个数

## 画面读法

- 上网格 = exGCD 迭代表：行 1 (old_r, r)、行 2 (old_s, s)、行 3 (old_t, t)，每步商 q 同步滚动三行
- 下网格 = CRT 演算栏四行：通解形式 → 移项 → 逆元登场 → x 落地
- 堆里「验算」：x mod m 与 x mod n 同时命中才算数

## 本局演算（默认参数）

- 第一幕：exGCD(3, 5) → 3·2 + 5·(−1) = 1 → **3⁻¹ ≡ 2 (mod 5)**
- 第二幕：x≡2 (mod 3) 代入 x = 2+3k → 3k ≡ 1 (mod 5) → k ≡ 1·2 = 2 → **x = 8**
- 验算：8 mod 3 = 2 ✓，8 mod 5 = 3 ✓

## 为什么重要

- 《孙子算经》（约 4 世纪）：三三数之剩二，五五数之剩三，七七数之剩二——问物几何？
- RSA 解密用 CRT 提速 4 倍；FFT 卷积、大整数运算全靠「拆余数、各算各、再合并」
- 逆元是模世界的除法：没有它，模运算只能加減乘——密码学直接瘸腿

## 怎么练

- 🎲 换素数模数与余数再跑——注意解 x 永远存在且唯一（mod p₁p₂）
- 手算：x≡1 (mod 4)，x≡2 (mod 7)？（x = 1+4k ≡ 2 → 4k≡1 (7) → k≡2 → x=9）
- 思考：模数不互质会怎样？（解可能不存在——gcd 不为 1 时 CRT 的「唯一」破产）
