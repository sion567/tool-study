# 随机游走·赌徒破产

## 一句话

公平硬币 ±1 元游走：P(先到 100 | 本金 50) = **50%**，期望时长 = 起点×终点差 = 2500 局。

## 不变量

- 公平游戏：P(暴富) = 本金/目标（线性插值）
- 期望游戏时长 = 起点 × (目标−起点)
- 游走无记忆——**赌徒谬误的解药**："已经输了很多该反弹了"在数学上毫无根据

## 演示剧本（种子 42）

本金 50 → 锯齿游走 → **第 1194 步暴富**（运气好的一个平行宇宙）。

## 庄家的绝望公式

庄家优势 2%（赢 0.49/输 0.51）时：

```
P(暴富) = (1−(19/21)^50)/(1−(19/21)^100) ≈ 2%
```

赌场不需要出千——**略占优 + 你破产即出局**就赢走一切。止损线的数学基础。

## 延伸

一维随机游走 = 布朗运动雏形（爱因斯坦 1905 解释花粉运动）→ 期权定价（Black-Scholes）。

## 怎么练

- 白纸算：本金 90、目标 100 时 P(暴富) = ？（90%）
- 思考：庄家优势为 0 但赌场有"抽水"（每局亏一点）——破产概率如何变化？（必然破产）
