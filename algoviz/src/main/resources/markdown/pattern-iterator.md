# 迭代器模式

## 一句话

怎么走封装在迭代器里，调用方只问 hasNext/next——for-each 是它的语法糖。

## 不变量（意图层）

- 游标状态活在迭代器内部：调用方永远不碰下标
- 换一种集合（链表/树），调用方代码不变——变的只是迭代器内部

## 🔗 本项目哪里用到了

- 反向引用：播放器遍历 Trace.steps 就是它——`List<Step>` 换成懒加载流，UI 零改动

## 怎么练

- 🎯 预测页：盯堆面板 `@2.cursor` 逐帧右移——next 之后才动
- 三个元素遍历完，hasNext 返回 false 那帧也要能预测

## 变体

- 变体=java.util.Iterator 协议、分页迭代器、流式惰性求值
