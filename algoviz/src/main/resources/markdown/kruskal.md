# Kruskal MST

## 一句话

按权重排序所有边，逐边尝试用并查集判环——不闭环才加。

## 不变量

- 并查集判环：两端同根 → 加边会形成环 → 跳过
- 排序后逐边贪心——与 Prim 的区别：Kruskal 从全局最小边开始，Prim 从起点扩展

## 对比 Prim

| | Prim | Kruskal |
|---|---|---|
| 策略 | 从起点扩展 | 全局最小边 |
| 适用 | 稠密图 | 稀疏图 |
| 判环 | 不需要（逐节点） | 并查集判环 |

## 怎么练

- 白纸推 9 条边的排序和逐边加入过程
- 思考：为什么并查集判环比 DFS 判环更高效
