# LSTM 门控

## 一句话

三门（遗忘/输入/输出）+ 细胞状态 c 传送带——**梯度沿 c 直通**，RNN 的消失问题在此被治愈。

## 不变量

- c_t = f⊙c_{t-1} + i⊙c̃：遗忘门决定留多少旧记忆、输入门决定写多少新内容
- h_t = o⊙tanh(c_t)：输出门决定露出多少——h 只是被过滤的"读出"，长期记忆活在 c 上
- 门值 ∈ (0,1) 全部由 sigmoid 产生——**可学习的阀门开度**
- 梯度直通：∂c₅/∂c₄ = f₅——对照 RNN 的 w_h⁴ = 0.41 衰减

## 与 RNN 对照（同一序列 [1,0,1,1,0]）

- RNN：h 被每步重写 → 早期输入的信息逐步稀释
- LSTM：c 传送带跨步传递 → f 接近 1 时记忆几乎无损
- 参数量：约 RNN 的 4 倍（三门户 + 候选）

## 画面读法

- 时间线六列：x → c → h → 门值 f/i/o——黄圈 = 当前时间步
- 门值全程 ∈ (0.2~0.9)：开度随输入滚动变化
- 🎯 点选预测：猜下一帧哪些格更新（c/h/门值列）

## 怎么练

- 🎯 预测：暂停猜下一帧 f/i/o 值——自己算 σ(w·[x,h])
- 思考：为什么 c 用加法更新而 h 用乘法？（加法是梯度高速公路，乘法链是衰减链）
- 延伸：GRU 合并遗忘/输入门（2 门 3 状态）；Transformer 用注意力彻底取代循环
