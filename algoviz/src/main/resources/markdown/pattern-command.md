# 命令模式

## 一句话

请求打包成对象——排队、撤销、日志、宏，全成了对对象的操作。

## 不变量（意图层）

- Invoker 只认 Command 接口，不知道里面装的是什么
- submit 与 execute 彻底分离：先排队后执行

## 🔗 本项目哪里用到了

- 反向引用：播放器的「上一步」按钮本质就是命令+历史栈——每步 Step 是天然的可撤销单元

## 怎么练

- 🎯 预测页：submit 帧答案是「没对象被执行」；flush 才是执行帧
- 加撤销 = 队列换成双端栈；加日志 = 序列化命令——都是对对象的操作

## 变体

- 变体=可撤销命令（undo 栈）、宏命令（命令列表）、异步命令
