# GNN 图神经网络

## 一句话

**消息传递**：每个节点收集邻居特征，平均后更新自己——一层 = 看一跳邻域。

## 不变量

```
h'_v = mean(h_v ∪ 邻居的 h)
GCN 公式：H' = Â·H·W（Â = 加自环归一化的邻接阵）
```

## 演示数字

5 节点（环 + 弦），初始 [1,0,2,0,1]：
- 轮 1：A=1.00 B=1.00 C=0.75 D=1.00 E=0.67
- 轮 2：A=0.85 B=0.92 C=0.65 D=0.81 E=0.84

特征被邻域逐渐"拉平"——**过平滑**：层数太多所有节点趋同，通常 2~3 层最佳。

## 层数 = 感受野

1 层看 1 跳、2 层看 2 跳——想让节点知道全局就得堆深，
但过平滑挡路：这是 GNN 与 CNN 最大的差异。

## 怎么练

- 白纸算轮 1 的 C（(2+0+0+1)/4 = 0.75）
- 应用：分子性质（原子=节点/键=边）、社交推荐、知识图谱
