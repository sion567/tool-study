# 斐波那契三版对比

## 一句话

递归有大量重复子问题 → 备忘录缓存消除重复 → DP 从底向上 + 空间优化——**同一问题的三种记忆策略**。

## 三版对比

| 版本 | 时间 | 空间 | 关键改动 |
|---|---|---|---|
| 递归 | O(2ⁿ) | O(n) 栈 | 大量重复：fib(5) 算 2 次、fib(3) 算 5 次 |
| 备忘录 | O(n) | O(n) 缓存+栈 | 缓存已算过的结果，每个子问题只算一次 |
| DP | O(n) | O(1) | 从底向上填表，只保留前两个值 |

## 画面怎么读

- **递归版**：红圈标出重复调用的 fib 值——一眼看到浪费
- **备忘录版**：dp 数组逐格填入，缓存命中的跳过
- **DP 版**：从底向上逐格生长，只需前两个值

## 不变量

- fib(n) = fib(n-1) + fib(n-2)——三种版本都在算同一个递推式
- 备忘录消除重复 → DP 消除递归 → 空间优化消除缓存

## 怎么练

- 白纸画出 fib(5) 的完整递归树，数一数 fib(2) 被算了几次
- 对比三版的「做了多少次加法」
