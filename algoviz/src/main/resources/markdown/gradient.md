# 梯度下降与动量

## 一句话

x ← x − lr·L'(x) 是深度学习的引擎——**动量加惯性冲过小丘逃离局部谷**。

## 不变量

- 普通 GD：每步从零起跑——谷底来回小幅震荡，被中央小丘困在局部谷
- 动量：v = β·v + L'(x)、x ← x − lr·v——历史速度的指数加权平均
- 方向一致时加速、方向反转时抵消——**惯性穿越曲面**
- lr 大则震荡、β 大则冲得远：两个旋钮的取舍

## 画面读法

- 蓝线 = 双谷损失曲面 L(x)=0.1x⁴−x²+0.5（局部谷左、全局谷右）
- 蓝点 = 普通 GD 动点（在局部谷打转），绿虚线 = 动量轨迹（跨丘直抵全局谷）
- 两条轨迹从同一起点出发——同一梯度不同命运

## 优化器进化史

- GD → 动量（惯性）→ Adam（动量 + 自适应步长）——本演示两条主线各占一条
- lr 调度、随机重启、模拟退火——逃离局部最优的武器库

## 怎么练

- 跑模板代码：对比 12 步后两个 x 值
- 手算：x=0.6 处 L'=0.4·0.216−1.2=−1.114 → 普通 GD 第一步 x=0.6+0.089=0.689——顺着切线爬坡
- 思考：动量为什么能冲过小丘？（谷底时速度不为零——惯性带它越过上升坡）
