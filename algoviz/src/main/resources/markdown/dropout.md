# Dropout 正则化

## 一句话

训练时随机杀一半神经元（保留值 ÷keep 预缩放）——**推理时全员上岗零开销**。

## 不变量

- inverted dropout：训练时预缩放 ÷keep → 期望不变 → 推理路径零调整
- 每帧不同 mask：网络被迫学"冗余表征"——任何特征不能只依赖单一路径
- 过拟合 = 背诵训练集；Dropout = 每帧换半个考官——**逼你学会规律而不是背题**

## 画面读法

- 三帧训练：mask 序列不同（灰 0 = 被置零）—— alive 计数在 3 上下波动
- 推理帧：全员上岗（黄圈全亮）——与训练帧形成行为反差

## 与 BatchNorm 并称正则化双子星

- Dropout 随机杀神经元、BatchNorm 把分布拉回正态——两个正交的稳定化手段
- Transformer 里 attention dropout 仍是标配

## 怎么练

- 跑模板代码：固定种子 mask 可复现——数一数每帧活的个数（期望 3）
- 思考：为什么推理不需要缩放？（inverted 把 ÷0.5 提前做进训练——期望在训练时就已对齐）
- 延伸：DropConnect 权重级 dropout、Label Smoothing 标签级正则——同一思想的不同粒度
