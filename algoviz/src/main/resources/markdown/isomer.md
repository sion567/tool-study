# 分子结构·同分异构

## 一句话

同样的分子式 C₄H₁₀，两种碳骨架——**度序列不同必非同构**：连接方式才是分子的身份，原子清单不是。

## 不变量

- 度序列（每个碳连几个碳，排序后）是图同构的不变量：序列不同 → 必非同构
- 正丁烷 [1,2,2,1]（链）vs 异丁烷 [3,1,1,1]（星）——一眼判决
- 结构差 1 根键 → 物理差一截：沸点 −0.5°C vs −11.7°C

## 画面读法

- 幕一：C1—C2—C3—C4 链状骨架逐键生长（边 = C-C 键）
- 幕二：C1 中心连三支的星形——同样的 4 个碳、3 根键，拓扑完全不同
- 🎯 点选预测：暂停猜下一根键连哪两个碳——度序列在你脑中生长

## 沸点为什么不同

- 支链越多分子越「圆」→ 范德华接触面越小 → 分子间作用力越弱 → 沸点越低
- C₅H₁₂ 三兄弟排队：正戊烷 36.1°C、异戊烷 27.9°C、新戊烷 9.5°C——🎲 换展品看它们

## 图论视角

- 碳骨架 = 一棵树（n 个碳 n−1 根键）：同分异构计数 = 树的同构类计数
- C₅H₁₂ 3 种、C₈H₁₈ 18 种、C₂₀H₄₂ 366319 种——异构体数目爆炸式增长
- 石油精炼的辛烷值：支链越多抗爆性越好——异构化反应是炼油厂的钱袋子

## 怎么练

- 🎯 预测：两种骨架的判决步，猜"同构/非同构"再看揭晓
- 手算：C₄H₁₀ 之外 C₃H₈ 有几种？（1 种——丙烷只有链状）
- 思考：度序列相同就一定同构吗？（不一定！C₄ 一圈+1 碳尾 vs……需进一步检验——但序列不同必不同构，这一半是铁律）
