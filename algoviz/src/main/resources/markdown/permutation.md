# 全排列（回溯）

## 一句话

每层选一个没用过的元素，递归完撤回——**回溯 = 试 → 撤 → 试下一个**。

## 不变量

- 每层选一个没用过的元素（used 剪枝跳过重复）
- 递归完撤回（used[i] = false + current.remove）——让同层试下一个候选
- N 个位置每层 N 个候选 → N! 个叶子

## 画面

- 栈面板逐层压弹 = 回溯的「试→撤」过程
- current 数组实时显示当前排列的构建过程
- 蓝色 = 在递归栈上（还没撤回的选择）

## 回溯三步曲

1. **选择**：把候选放入 current
2. **递归**：带着这个选择深入下一层
3. **撤销**：递归回来后移除候选，让同层试下一个

## 怎么练

- 🎯 盯栈面板：每层压栈 = 做了一个选择，弹栈 = 撤销
- 白纸画选择树：根到叶的每条路径 = 一个排列
- 思考：如何只打印前 3 个排列就提前终止？（剪枝的另一种形式）
