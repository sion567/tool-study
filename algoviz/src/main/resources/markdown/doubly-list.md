# 双链表插入 / 删除

## 一句话

每节点多一根 prev 箭——改一处要同步改两根，漏一根链就断。

## 不变量

**prev 与 next 互为镜像**：`A.next = B ⟺ B.prev = A`。
任何操作做完，这条镜像必须处处成立——它就是双链表版本的"已就位区间"。

## 插入 = 四根箭

在 after 后插 n：

```
① n.prev  ← after          （新节点回头）
② n.next  ← after.next     （新节点前指）
③ 右邻.prev ← n            （右邻回头）
④ after.next ← n           （左邻前指）
```

画面上先动 ①②（只动新节点，链还是原样），再补 ③④（镜像恢复）。

## 删除 = 两根箭

```
del.prev.next ← del.next   （左邻跳过它）
del.next.prev ← del.prev   （右邻回头指左邻）
```

**双链表删已知节点 O(1)**——prev 现成，不用像单链表那样先走一遍。

## 为什么要多花 8 字节

- LRU 缓存：哈希表定位节点 + 双链表 O(1) 摘除/挪头——整个缓存操作 O(1)
- 倒序遍历、区间删除、Java 的 LinkedList、Linux 内核 list_head 全是双链
- 代价：每节点多一根指针（64 位系统 8 字节）

## 怎么练

- 白纸推插入四步的顺序：为什么 ③④ 必须在 ①② 之后？（先动 after.next 就丢了右邻）
- 变形：只给 head，怎么 O(1) 删尾节点？（双链表 + tail 指针——这就是为什么 Deque 存在）
