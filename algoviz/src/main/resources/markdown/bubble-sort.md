# 冒泡排序

## 一句话

相邻两个比一比，大的往后换——每一轮最大的数像气泡一样冒到尾部。

## 生活故事

体育课按身高排队：老师让相邻两人两两比身高，高的换到右边。一遍走完，最高的已经站到队尾；再走一遍，第二高的也到位了……

## 不变量（意图层）

- 每轮结束：**尾部 i 个元素已就位且有序** → 这就是内层上界 `n-1-i` 的来历，**不用背，能推**
- 交换三行 `t=a[j]; a[j]=a[j+1]; a[j+1]=t`：先记住再覆盖，否则 x 就丢了
- 第 7 行执行完的瞬间，数组里**有两个相同的值**——这是真实执行中间态，不是 bug

## 什么时候用 / 代价

- 教学 / 面试口粮，生产几乎不用；O(n²) 比较、O(n²) 交换
- 优点：稳定；写起来最短；`n-1-i` 边界是最经典的默写考点
