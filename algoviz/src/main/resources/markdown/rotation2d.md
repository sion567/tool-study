# 线性代数·2D 旋转

## 一句话

**矩阵乘向量 = 几何变换**：R(θ) 转多边形，每步一次矩阵乘法。

## 不变量

```
x' = x·cosθ − y·sinθ
y' = x·sinθ + y·cosθ
```

R(θ) 是正交矩阵：列向量单位长且互相垂直 → **保持长度、角度、面积**——只动位置，不动几何。

## 画面读法

- 蓝色三角形每步转 30°，六步转半圈：顶点 A (2,0) → (−2,0)
- 蓝点 = 三个顶点，形状全程不变

## 为什么重要

- 游戏引擎每帧：位置 = R·位置 + 平移（组合 = 矩阵连乘）
- 100 万顶点旋转 = 300 万乘加——GPU 每毫秒完成：**显卡就是矩阵乘法机器**
- 延伸：缩放 = 对角阵、切变 = 三角阵；3D 加一维，四元数避免万向锁

## 怎么练

- 白纸算 R(90°)·(2,0) = (0,2)（cos90=0, sin90=1）
- 思考：连乘 R(30°)R(30°)R(30°) = ?（R(90°)——旋转矩阵成群 SO(2)）
