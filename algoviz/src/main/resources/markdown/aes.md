# 对称·AES-128

## 一句话

10 轮 SPN：SubBytes → ShiftRows → MixColumns → AddRoundKey——**每轮全状态替换**（对照 SM4 每轮只动 1/4）。

## 不变量

- 状态 4×4 字节（列主序 in[r+4c]），每轮 16 字节全换
- SubBytes = GF(2⁸) 求逆 + 仿射——**有代数式的 S 盒**（对照 SM4 黑盒查表）
- MixColumns：GF(2⁸) 上乘 MDS 矩阵 [2 3 1 1; …]——1 字节改动散满一列
- 末轮去 MixColumns：扩散已完成，省一次矩阵乘
- FIPS-197 C.1：key=000102…0f、plain=001122…ff → 69c4e0d8 6a7b0430 d8cdb780 70b4c55a

## 画面读法

- 4×4 状态网格逐帧更新（每帧 2 轮，16 格全变——🎯 预测"全变"也是练）
- 密钥扩展帧：Rcon 常量 + RotWord/SubWord 逐字发酵
- GF(2⁸) 乘法：xtime × 2 = 左移 + 条件异或 0x1b——"模 x⁸+x⁴+x³+x+1"

## 与 SM4 对照

| | AES-128 | SM4 |
|---|---|---|
| 结构 | SPN 全状态 | 不均衡 Feistel 部分 |
| S 盒 | 代数构造式 | 黑盒查表 |
| 轮数 | 10 | 32 |
| 线性层 | MixColumns 矩阵 | L 五路旋转异或 |

## 怎么练

- 🎲 换随机密钥：轮密钥全变，密文结构不变
- 🎯 预测：暂停轮中猜哪些格变（全变——练的是"SPN 直觉"）
- 白纸算：GF 乘 2×0x80 = 0x1b（最高位溢出时异或 1b——多项式模的现场）
