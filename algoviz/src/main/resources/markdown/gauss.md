# 高斯消元

## 一句话

初等行变换不改变方程组的解——**消成上三角，再回代**。

## 不变量

三种初等变换（换行 / 倍乘 / 倍加）都保持同解——这是整个算法的合法性证明。

## 流程

1. **前向消元** O(n³)：R2←R2−R1、R3←R3−R1、R3←R3−3R2 → 上三角
2. **回代** 自底向上：z = 6/2 = 3 → y = 8−2z = 2 → x = 6−y−z = 1

## 画面读法

- 黄圈 = 正在消的行，绿 = 已成上三角的行
- 每步事件显示行运算式与结果行

## 数值稳定性（进阶）

主元太小要**选主元**（换最大行）——不然除以小数放大舍入误差。
工程实现都用 LU 分解（LAPACK）。

- 白纸推本例三次行变换的每一行
- 思考：什么情况下无解/无穷解？（某行全 0 但 b≠0 / 全 0）
