# 矩阵乘法

## 一句话

C(i,j) = A 的第 i 行 与 B 的第 j 列 **对应相乘再相加**——三重循环，一个 Σ。

## 生活故事

班费结账：A 是「人数×商品」的购买表，B 是「商品×单价」的价格表，C 就是每个人该付的钱——**人碰商品，商品碰单价**，两次查询一次乘法。

## 不变量（意图层，数学的命门）

- **C(i,j) 只由 A 的第 i 行和 B 的第 j 列决定**，与其他任何行列无关 →
  - 所以能**并行**（每个格子一个线程互不打扰）
  - 所以能**分块**（大矩阵切块后块间公式形状不变——BLAS 加速的根基）
- 累加器清零 → 逐项加 → **K 项加完定格，从此不变**

## 画面怎么读（右侧画布）

- **橙色行**（A）/ **橙色列**（B）= 本步正在读取的行与列——它们"决定"下方 C 的黄格
- **C 的黄圈格** = 部分和在累加：7 → 25 → 58，逐帧长成
- **绿色格** = 已定格（三项加完，从此不变）

## 逐行看（右侧代码）

1. `C[i][j] += A[i][k] * B[k][j]`——第 9 行就是全部：定位（i,k）、（k,j）、（i,j）三个下标
2. k 循环是 Σ 的展开：`Σ(k=0..2) A[i][k]·B[k][j]`
3. 复杂度 O(mnk) = 8 次乘法——Strassen 能少但代价大，工程上靠分块+SIMD

## 怎么练（健身房，蓝图 §2.5-C）

1. 🎯 预测页：**只问 C 的格子**——移动行列的帧答案是「没格子写数」
2. 白纸算 C[1][0]：口头走一遍 4×7 + 5×9 + 6×11 = 139，再开工具对答案
3. 关掉工具，问自己：为什么 C 的其他格子"同时"算也不会打架？（答案就是不变量）
