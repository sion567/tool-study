# Bellman-Ford

## 一句话

逐边松弛 V-1 轮——**可以处理负权边**（Dijkstra 不行），还能检测负环。

## 画面

- 蓝色节点 = 未出圈，绿 = dist 已确定（逐轮更新）
- 黄圈 = 本步松弛的边
- 堆面板 `DistTable` 距离表逐帧跳动

## 不变量

- 第 k 轮松弛后，dist[u] ≤ 从 src 走 ≤ k 条边到 u 的最短距离——逐轮扩展可到达范围
- V-1 轮后收敛（无负环）；额外一轮可检测负环

## 对比 Dijkstra

| | Dijkstra | Bellman-Ford |
|---|---|---|
| 负权边 | ❌ | ✅ |
| 复杂度 | O((V+E) log V) | O(V·E) |
| 策略 | 贪心出圈 | 逐轮松弛 |

## 怎么练

- 白纸推 5 轮松弛，每轮记 dist 变化
- 思考：为什么负权边对 Dijkstra 是灾难，对 Bellman-Ford 无影响
