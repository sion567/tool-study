# 反应过程·酸碱滴定

## 一句话

pH 曲线三段式：**缓冲区平坦（pH=pKa）→ 等价点陡升（弱酸 pH>7）→ 过量区放飞**——拐点位置暴露酸的强弱。

## 不变量

- 缓冲区 Henderson-Hasselbalch：pH = pKa + log(Vb/(Ve−Vb))——酸碱库存互为缓冲
- 半等价点：酸碱各半 → **pH = pKa**（实验测 pKa 就靠这一点）
- 等价点：弱酸根水解 → pH = 7 + ½(pKa + lgC) > 7——不是误差，是化学

## 画面读法

- 蓝线 = 弱酸滴定曲线，绿虚线 = 强酸强碱对照（等价点 pH=7、无缓冲区）
- 三段式肉眼可见：平坦 → 爬坡 → 陡升 → 汇合
- 🎲 换酸浓度：等价点体积移动（Ve = Va·Ca/Cb），曲线形状不变——计量与强度的分工

## 本局读数

- 等价点 25.0mL，弱酸 pH=8.88（>7：Ac⁻ 偷走 H₂O 的 H⁺）
- 半等价点 12.5mL：pH=pKa=4.76——课本数字的实验出处
- 强酸对照在等价点恰好 7.00：两条曲线在此「分手又汇合」

## 指示剂选型

- 酚酞变色区 8.2~10.0：正落在弱酸陡升段 ✓
- 选错指示剂 = 拐点读数漂移——甲基橙（3.1~4.4）只配强酸强碱

## 怎么练

- 🎲 预测：暂停在缓冲区，猜下一滴 pH 变多少？（几乎不变——这就是缓冲）
- 白纸算：Ve 减半（浓度减半）时等价点 pH 怎么动？（pH=7+½(pKa+lgC) 变小 0.15）
- 生活注释：血液 H₂CO₃/HCO₃⁻ 缓冲对把 pH 钉在 7.35~7.45——平坦段救你的命
