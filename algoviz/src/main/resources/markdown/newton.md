# 牛顿迭代法

## 一句话

在曲线上作切线，切线与 x 轴的交点就是更好的近似——重复到精度封顶。

## 不变量

- x_{n+1} = x_n − f(x_n)/f'(x_n)，几何意义就是"沿切线滑到零点"
- **平方收敛**：误差 e → e²/(2|x*|)，每步有效数字翻倍

## 直觉

从 x₀=2 解 x²−2=0（求 √2）：

| 步 | x | 误差 |
|---|---|---|
| 0 | 2 | 0.59 |
| 1 | 1.5 | 0.086 |
| 2 | 1.41667 | 0.0025 |
| 3 | 1.41422 | 2e-6 |
| 4 | 1.41421356 | 4e-12 |

看误差列：0.59 → 0.086 → 0.0025 → 2e-6 → 4e-12，**每步平方**。

## 为什么重要

- `Math.sqrt` 的底层思路之一：查表/多项式给初值 + 1~2 步牛顿精修
- 除法、开方、求根：硬件没有"直接算"的电路，全是迭代逼近

## 坑

- 初值离根太远可能发散或跳到别的根（f'≈0 时切线几乎水平，下一步飞出天际）
- 多根时收敛到哪个取决于初值落在谁的盆地

## 怎么练

- 白纸推：x₀=3 求 √2，写出前 3 步
- 对比二分法（线性收敛，每步 1 位）和牛顿（平方收敛）差多少
