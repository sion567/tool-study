# RNN 循环神经网络

## 一句话

同一个细胞滚动每个时间步：`h_t = tanh(w_x·x_t + w_h·h_{t−1})`——**h 是序列的记忆**。

## 不变量

- 参数在所有时间步共享——序列任意长、参数量不变
- h₅ = 0.63：整条序列被压缩成一个向量
- 梯度沿时间连乘 w_h → 消失/爆炸（BPTT 的痛点）

## 演示数字

x = [1,0,1,1,0]，h₀=0，w_x=1，w_h=0.8：
h₁=0.76 → h₂=0.54 → h₃=0.89 → h₄=0.94 → h₅=0.63
h₅ 对 h₁ 的梯度 ∝ 0.8⁴ = 0.41——越长衰减越狠。

## 与 Transformer 的交接

RNN 必须逐步滚动（难并行）；LSTM/GRU 用门控续命；
Transformer 用注意力一步到位——"隐藏状态"思想被继承，"循环"被抛弃。

## 怎么练

- 手算本例前 3 步的 tanh
- 思考：w_h = 1.5（>1）会怎样？（梯度爆炸）
