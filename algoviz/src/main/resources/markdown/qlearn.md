# 强化学习·Q-Learning

## 一句话

Q(s,a) ← Q(s,a) + lr·(r + γ·max Q(s′) − Q(s,a))——**奖励沿经验反向传播，贪婪路径自己浮出来**。

## 不变量

- TD 误差 = 现实(r+γ·maxQ′) − 预期(Q)——误差驱动 Q 向"更好的估计"挪动
- γ<1：远处的奖励打折——离 G 越远 Q 越小（画面顶行递增 0.05→0.72 正是 γ 的指纹）
- 撞墙 −1：负奖励也是老师——"此路不通"被记进 Q 表
- 贪婪策略沿 max Q 走——训练期以 ε 概率随机探索（exploitation vs exploration）

## 画面读法

- 网格格值 = 每格 max Q（未来奖励期望）：从 G 反向递减（1.00→0.86→0.72→…）
- 黄圈 = 本步 TD 更新格——奖励传播的波前
- 🎯 点选预测：猜下一帧哪格 Q 值变（沿经验路径）

## 逐轮传播的观察

- 12 轮后奖励才照亮整条路径：**每轮约反向传播 1 格**——TD 学习的"接力"本质
- 起点格的 Q 最后才变正——路径是从终点"长"回起点的

## 怎么练

- 🎯 预测：暂停波前帧，猜下一帧哪格被点亮
- 思考：γ=1 会怎样？（奖励不打折——Q 发散风险；γ=0 则只看眼前奖励，学不到远期）
- 延伸：Deep Q-Network 用神经网络近似 Q 表——Atari 游戏的同款数学
