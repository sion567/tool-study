# 反应过程·反应动力学

## 一句话

一级衰减 t½ = ln2/k **恒定**（放射性钟表），二级 t½ 越走越长——**半衰期守不守恒，就是反应级数的指纹**。

## 不变量

- 一级 [A] = A₀e^(−kt)：每过 ln2/k 浓度雷打不动减半——指数衰减"记不住"自己剩多少
- 二级 [A] = A₀/(1+kA₀t)：浓度掉一半，速率跟着掉——越消耗越「恋战」
- 实验判级数：ln[A]-t 是直线 → 一级；1/[A]-t 是直线 → 二级

## 画面读法

- 蓝线 = 一级（动点按固定节拍阶梯下行），绿虚线 = 二级对照（越掉越慢）
- 堆里「二级 t½」一路上涨——这就是两条曲线分道扬镳的原因
- 🎲 换 k：曲线陡度变、半衰期变，但"一级恒定 vs 二级增长"的对比永不变形

## 同一个数学的家族

- 碳-14 测年（t½=5730 年恒定）：考古学的钟表
- 药物代谢半衰期：给药间隔就是照它排的
- 核废料存储：钚-239 的 t½=24100 年——恒定得让人头疼

## 怎么练

- 白纸算：一级反应 3 个半衰期后剩几？（1/8——0.5³）
- 🎲 预测：暂停中段猜下一帧 [A] 值——你会不自觉用"减半节拍"，这就是级数直觉
- 思考：为什么二级曲线"尾巴长"？（速率 ∝ [A]²，浓度低时平方更小）
