# 状态模式

## 一句话

同一个按钮，行为随状态对象变——切换由状态自己驱动（对比策略：外部换）。

## 不变量（意图层）

- 上下文的行为由当前状态对象决定：换状态 = 换引用
- 关键区别：策略由外部换实现，状态由状态对象自己触发切换

## 🔗 本项目哪里用到了

- 反向引用：播放器的 ▶/⏸ 按钮就是典型双状态——playing 时按=暂停，paused 时按=播放

## 怎么练

- 🎯 预测页：三次 pressPlay，@1.state 的箭头在 Paused/Playing 间转圈——每次「委托到谁」要能答对
- 新状态 = 加一个 State 实现类，Player 一行不改

## 变体

- 变体=状态机表驱动（转移表）、Spring StateMachine；与策略的区别只在「谁来换」
