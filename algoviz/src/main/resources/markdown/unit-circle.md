# 单位圆→正弦波

## 一句话

**sin(θ) 就是单位圆上动点的 y 坐标**——不是公式，是几何投影。

## 画面怎么读

- **左半**：单位圆 + 橙色动点沿圆周逆时针转 + 蓝色投影线（到 x 轴 = sin 值）
- **右半**：蓝色 sin 波逐帧生长，绿色虚线 cos 波同步
- **橙色圆点**在左图圆周上的 y 坐标 = 右图波上对应点的 y 值

## 不变量（意图层）

- sin(θ) = 动点的 y 坐标——**sin 是几何投影，不是公式**
- cos(θ) = 动点的 x 坐标——虚线绿波 = 水平投影
- 波的周期 = 2π = 圆转一整圈

## 为什么重要

理解了「sin = 圆的投影」，以下全部变得直觉化：
- 为什么 sin 的最大值是 1（圆的半径）
- 为什么 cos 超前 sin 90°（x 和 y 差 90°）
- 为什么 sin(π/2) = 1（动点在圆的最高点）
- 为什么 sin(π) = 0（动点在圆的最左端）

## 怎么练

- 🎯 逐步走：每帧预测 sin 值会变大还是变小
- 关掉工具，手画单位圆 + 8 个均匀角度点，标出 sin 值
- 试 cos 波：同样的圆，投影到 x 轴
