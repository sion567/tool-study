# 朴素贝叶斯分类

## 一句话

P(类|邮件) ∝ P(类)·Π P(词|类)——**乘法链把每封信压成一个分数**，大者胜。

## 不变量

- "朴素" = 假设词与词条件独立——现实里不真，但好用
- 先验 P(spam)=0.6 / P(ham)=0.4："不看内容时押谁"——每个词都在修正押注
- 拉普拉斯平滑：没见过的词 +1/(词表+类数)——**不会一票否决**
- 本局："免费 中奖" → score_spam 0.072 ≫ score_ham 0.006 → 判定 spam

## 画面读法

- 概率表：每个词的 P|spam 与 P|ham（拉普拉斯平滑后）
- 黄圈 = 参与乘法链的词（出现在待分类邮件里的）
- 判定行 = 似然比：>1 押 spam、<1 押 ham

## 为什么"朴素"还这么强

- 独立假设明显假（"免费"+"中奖"强相关）——但分类只需要**分数相对大小**，不需要绝对精确
- 小数据也能跑、训练秒级、可解释——垃圾邮件过滤的常青基线

## 怎么练

- 跑模板代码：换邮件内容看判定翻转——"会议"邮件会判 ham
- 手算：score_spam = 0.6×(4/10)×(3/10) = 0.072——每个因子都对上画面
- 思考：把"免费"换成"会议"会怎样？（两个 ham 词 → ham 险胜——词数少时判据微弱）
