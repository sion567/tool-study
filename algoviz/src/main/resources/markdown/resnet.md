# 残差连接

## 一句话

y = F(x) + x 的 "+1"——**每层一条梯度高速路**，10 层后普通网梯度 10⁻⁵ vs 残差网 ~1。

## 不变量

- 反向：∂L/∂x = ∂L/∂y·(F'(x)+1)——恒等项不衰减
- 退化现象：56 层比 20 层训练误差**还高**——不是过拟合，是深层训不动（He 2015）
- 恒等映射哲学：最坏 F(x)=0 时网络退化为恒等——"至少不比浅层差"的下限保证
- 与 LSTM 的 c 传送带同源：**给梯度开一条"不乘"的高速路**

## 画面读法

- 双列赛跑：普通列每层 ×0.3 十层缩 5 万倍；残差列每层 ×1.3 十层涨 13 倍
- 🎯 点选预测：猜下一层两列的值——衰减是乘法直觉，直通是加法直觉

## 外溢

- Transformer 每个块都是残差块——"加一条直通线"是深层网络的标准姿势
- 152 层 ImageNet 3.57%：2015 年的里程碑

## 怎么练

- 手算：5 层后普通网梯度 = 0.3⁵ ≈ 0.00243、残差网 = 1.3⁵ ≈ 3.71——差距 1500 倍
- 思考：为什么恒等映射是"下限保证"？（最坏情况网络啥也不学，也不会比删掉这些层更差）
