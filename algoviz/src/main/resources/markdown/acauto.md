# AC 自动机

## 一句话

Trie + fail 指针 + **一次扫描命中全部模式**——KMP 的多模式推广。

## 不变量

- fail(节点) = Trie 中该串的**最长真后缀**——KMP 的 next 推广到树上
- 扫描：文本指针只前进不回退——mismatch 时状态沿 fail 跳
- 命中一个模式后沿 fail 链还能捡到嵌套短模式（she 命中时 he 也命中）
- 复杂度 O(文本 + 模式总长 + 命中数)——模式再多只扫一遍

## 本局演算

- 模式 {he, she, his, hers}、文本 "ushers"
- 扫描到 e（位 3）：状态进入 she → **she 命中** + 沿 fail 链 → **he 也命中**
- 扫描到 s（位 6）：状态进入 hers → **hers 命中**——3 次命中 1 次扫描

## 画面读法

- 上网格 = 文本扫描（上行字符、下行进入的状态）
- 下网格 = Trie 节点表（fail 列 = 最长真后缀转移）
- 🎯 点选预测：猜下一帧是否命中（扫描位是否落在词尾）

## 怎么练

- 手推：fail(she 节点) 为什么是 he？（最长真后缀——he 在 Trie 里）
- 思考：为什么文本指针永不回退？（fail 跳已经"退够了"——KMP 定理的 Trie 版）
- 延伸：grep 多模式、入侵检测规则匹配、DNA 序列比对全是它
