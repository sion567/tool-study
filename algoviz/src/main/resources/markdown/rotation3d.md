# 线性代数·3D 旋转

## 一句话

姿态 = 3×3 正交矩阵 R——**每列是"本地坐标轴转到哪了"**；正交变换保长度保夹角（RᵀR=I）。

## 不变量

- 8 顶点 ‖v‖ ≡ √3：旋转不改长度——画面上立方体"变形"只是透视，数学上刚体
- R = Rz·Ry·Rx 外旋复合：**矩阵顺序不可交换**（换序转到的姿态不同）
- 绕 Z = 2D 旋转的推广（z 行列不动）；绕 X/Y 才是 3D 新增的自由度
- 万向锁：Y 转 90° 时 Z 轴与 X 轴在世界系重合——**两组欧拉角同一姿态，丢一个自由度**

## 画面读法

- 立方体线框：近粗远细 + 近大远小（弱透视 fov/(fov−z)）——深度感全靠这两招
- 三色轴：X 红 / Y 绿 / Z 蓝；左上角 = 当前矩阵 R 逐帧变化
- ⚠ 帧：万向锁现场——(Z30,Y90,X0) 与 (Z50,Y90,X20) 矩阵逐元素相同

## 万向锁专节

- 欧拉角 3 个数直觉最好，但**参数化有奇异点**：中间轴 ±90° 时首尾轴共线
- 真实事故：飞船/机械臂按欧拉角做控制，转到奇异姿态时"控制器抽风"
- 解法不在欧拉角内部——**换表示**：四元数（4 个数、无奇异、slerp 平滑插值）或轴角
- 代价：四元数不直观（4 个数怎么看姿态？）——所以引擎内部用四元数、UI 显示用欧拉角

## 怎么练

- 🎲 换步进角 15/30/45°：轨迹粗细不同，姿态序列相同——步长不影响数学只影响采样
- 手算：Rz(90°) 作用 (1,0,0) → (0,1,0)；Rx(90°) 作用 (0,1,0) → (0,0,1)——对照画面
- 思考：为什么 R 必须正交？（剪切/缩放不是刚体——RᵀR=I 就是"纯旋转"的代数定义）
