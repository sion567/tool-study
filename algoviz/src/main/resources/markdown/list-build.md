# 头插法 / 尾插法建表

## 一句话

头插 O(1) 但逆序，尾插 O(1) 且保序但要多养一个 tail 指针。

## 不变量

- **头插两步序**：`newNode.next ← head`，再 `head ← newNode`——顺序反了旧链就丢
- **尾插两步序**：`tail.next ← newNode`，再 `tail ← newNode`

## 为什么头插会逆序

越晚插的越靠前。{1,2,3} 依次头插：

```
插 1:  1
插 2:  2 → 1
插 3:  3 → 2 → 1     ← 正好是输入的倒序
```

这个"缺陷"其实是特性：**链表反转** 的另一种写法就是重建时全部头插。

## 头插 vs 尾插的本质

| | 头插 | 尾插 |
|---|---|---|
| 语义 | 后进先出 = **栈** | 先进先出 = **队列** |
| 指针开销 | head 一个 | head + tail 两个 |
| 保序 | ✗（自动反转） | ✓ |

## 什么时候只给 head

面试常考：**只给 head 的单链表，怎么保序建表？**
两个答案：① 头插建完再整体反转（两次 O(n)）；② 每次走到尾再插（O(n²)，不行）。
正确姿势：建一个 dummy 哨兵 + tail，或干脆头插后反转。

## 怎么练

- 白纸推：{5,2,9} 头插三步，画出每步 head 的指向
- 变形：头插法插入时两步写反（先挪 head）会发生什么？（旧链彻底丢失）
