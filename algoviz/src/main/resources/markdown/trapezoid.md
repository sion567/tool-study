# 逐段积分误差对照

## 一句话

同一函数三法赛跑：**黎曼 O(1/n)、梯形 O(1/n²)、辛普森 O(1/n⁴)**——n 翻倍误差分别缩 1/2、1/4、1/16。

## 不变量

- f(x)=x² on [0,1]，真值 1/3≈0.3333——三个近似值逐行逼近
- 左黎曼：矩形贴左端点——少算边界 → 一阶误差
- 梯形：边界多算一个点 → 二阶误差
- 辛普森：两点间抛物线插值 → 四阶误差

## 画面读法

- 收敛表逐行填：每列相邻两行的**比值**就是误差阶
- 辛普森列用科学计数法：n=32 时已 <10⁻⁶
- 🎯 点选预测：猜新行的三个误差值——你要按"比例缩"预判

## 性价比思维

- 想精度 ×16：黎曼 16 倍算力、梯形 4 倍、辛普森 2 倍
- 辛普森每段 3 个点（2 倍算力）——用插值多项式的阶换收敛速度

## 怎么练

- 手算：n=4 左黎曼 = (0+0.0625+0.25+0.5625)/4 = 0.21875——误差 0.1146
- 🎯 预测：暂停 n=16 帧，按比例猜 n=32 行
- 思考：为什么辛普森对 x² 有"额外准"？（抛物线插值对二次函数是**精确**的——误差阶体现不出来）
