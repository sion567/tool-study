# 汉诺塔

## 一句话

递归分治的祖师爷：让开 → 挪最大 → 盖上，步数恒为 **2ⁿ−1**。

## 不变量

- 大盘永不上小盘
- 递归三问：① 子问题同构（挪 n−1 个盘）② 出口（n=0）③ 步数 T(n) = 2T(n−1)+1 → 2ⁿ−1

## 画面读法

- 三列 = 三根柱，数字 = 盘大小（上小下大）
- 黄圈 = 本步落下的盘；堆面板实时显示三柱内容

## 传说与数学

64 个金盘挪完世界终结：2⁶⁴−1 步 ≈ **5849 亿年**（每秒 1 步）。
指数增长 = 递归的复利——分治能把操作"说清楚"，但改不了指数本质。

## 怎么练

- 白纸推 n=3 的 7 步（就 7 步，值得手推一次）
- 思考：为什么步数不可能少于 2ⁿ−1？（最大盘要动，必须先挪开上面 n−1 个、再盖上）
