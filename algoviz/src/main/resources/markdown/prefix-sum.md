# 前缀和

## 一句话

`pre[i] = a[0]+…+a[i−1]` 预处理一次，任意区间和 `sum(l,r) = pre[r+1] − pre[l]` **O(1) 查询**。

## 不变量

pre[i] 恒等于前 i 项之和——区间和 = 两个前缀之差（容斥）。

## 典型用法

- 区间和查询 Q 次：暴力 O(nQ) → 前缀和 O(n+Q)
- 二维版：`sum(r1..r2, c1..c2)` 四个二维前缀容斥
- 变形：pre[j]−pre[i]=k 的对数 → 哈希表数出现次数（和为 K 的子数组）

## 怎么练

- 白纸推 {3,7,2,5,1} 的 pre 数组（0,3,10,12,17,18）
- 思考：为什么 pre[0]=0？（空和——让 sum(0,r) 不用特判）
