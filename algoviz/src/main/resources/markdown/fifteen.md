# 不变量·15 谜题可解性

## 一句话

合法滑动永远保持「逆序数 + 空格行」的奇偶——**一个改不动的数，把所有局面劈成两个永不相通的世界**。

## 不变量

- 横移：扁平行不变 → 逆序数不变
- 竖移：一枚牌跨过 3 个中间格 → 逆序数变化为偶数（±3±1 组合）
- 判据（宽为偶）：**逆序数 + 空格行（自底 1 起）为奇 ⇔ 可解**
- 对换两枚牌：逆序数 ±1 → 奇偶翻转 → 那个局面无论怎么滑都到不了

## 画面读法

- 4×4 棋盘 = 局面；下方扁平行 = 忽略空格后的 15 个数（数逆序用的"账本"）
- 第一幕逐个基准数逆序：黄圈 = 当前基准格；堆里「奇偶指纹」实时更新
- 第二幕对换两枚牌：逆序数 ±1，指纹翻转 → 无解判决

## 历史判决

- 1879 年「15 谜题风暴」：全美疯玩，赌局悬赏——因为有人偷偷**对换了两枚牌**
- 没人能滑回原局不是手笨：合法移动全部保奇偶，对换局面在另一个世界
- 一行数学终结了全国狂热——**不变量是组合数学的指纹鉴定科**

## 怎么练

- 思考：为什么 3×3 的 8 谜题判据不用空格行？（宽为奇：竖移跨 2 格，逆序数本身即不变量）
