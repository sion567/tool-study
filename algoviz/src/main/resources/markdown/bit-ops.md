# 位运算技巧

## 一句话

对二进制每一位独立操作——& 同 1 才 1，| 有 1 就 1，^ 不同才 1。

## 常见技巧

| 技巧 | 代码 | 用途 |
|---|---|---|
| 判断奇偶 | `n & 1` | 最低位 = 1 → 奇 |
| 消最低位 1 | `n & (n-1)` | 计算 1 的个数/判断 2 的幂 |
| 异或找不同 | `a ^ b` | 只出现一次的数 |
| 左移/右移 | `n << k` / `n >> k` | ×2ᵏ / ÷2ᵏ |
| 交换两数 | `a^=b; b^=a; a^=b;` | 不用临时变量 |

## 不变量

- 每个操作都是 O(1)——CPU 原生指令，比算术更快
- 位运算 = 把布尔逻辑并行应用到每一位

## 🔗 面试高频

- 只出现一次的数（其余出现两次 → 全 XOR）
- 判断 2 的幂（n & (n-1) == 0）
- 不用 + 求 a+b（^ + &<<1 递归）
