# 热学·热扩散

## 一句话

热量只从高温流向低温，绝热箱里 400 单位只能摊平——终态全场 6.25°C，**熵增的数值版**。

## 不变量

- 傅里叶定律：热流 ∝ 负温度梯度——温差越大，流得越快
- 绝热边界 = 镜像邻居 → 通量成对抵消 → **总热量严格守恒**
- 终态均温 = 总热量 ÷ 格数 = 400/64 = 6.25°C：守恒律直接锁死结局

## 画面读法

- 8×8 网格：格值 = 温度（°C），中心 2×2 初始 100°C，其余 0°C
- 黄圈 = 本帧值变化超过 0.1°C 的格子——**波前环**，热量沿它向外涌
- 🎯 这是物理批唯一支持**点选预测**的演示：猜下一帧哪些格子会变——波前环就是答案

## 数值方法的脾气

- 显式差分 T' = T + C·(四邻和 − 4T)：C ≤ 0.25 才稳定（否则数值爆炸——假物理）
- 摊平先快后慢：梯度大时猛流，梯度小时温吞——指数收敛
- 终局收敛到均温不是模拟「累了」，是守恒律 + 熵增的必然

## 同一个方程的家族

咖啡变凉、CPU 散热、污染物弥散、反扩散重建图像——全是 ∇²T 的变体。
**扩散方程时间反演不对称**：打得碎的鸡蛋拼不回去。

## 怎么练

- 白纸算：格数翻倍（热量不变），终态均温变几倍？（减半——均温 = 总热量 ÷ 格数）
- 🎯 预测：暂停在波前刚到角落那帧，猜下帧哪些格子变
- 思考：为什么 C > 0.25 会数值爆炸？（步子太大跨过了物理稳定域—— courant 条件的味道）
