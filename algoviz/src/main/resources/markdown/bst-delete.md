# BST 删除

## 一句话

找到之后别急着拔——**先问它有几个孩子**，三种情况三种断法；双子用中序后继补位。

## 生活故事

公司裁员一个中层：光杆（叶子）直接走；只带一个团队（单子），团队直接汇报给上级；带两个团队（双子），让**接班人**顶上——接班人是谁？右 subtree 里资历最浅（最小）的那个，他既服原左边的众，又压得住右边。

## 不变量（意图层）

- **删完必须仍是 BST：左 < 根 < 右**——三种断法都是为了让这条不被破坏
- 双子删除 = **换值不换节点**：后继的值抄进目标，然后把后继从右子树里删掉——后继必然无左孩子，所以第二刀永远落在情况①/②
- 递归版的手法与插入同源：`root.left = delete(root.left, val)` —— **接住删改后的子树重新挂**

## 三种断链（对着帧看）

| 情况 | 动作 | 画面标志 |
|---|---|---|
| ① 叶子 | return null，父指针落空 | 节点消失 |
| ② 单子 | return 唯一的孩子，父指针改指 | 8 的左孩子从 7 变 9（黄边） |
| ③ 双子 | 后继值抄进根（值变 5→7），再删右子树里的后继 | 根的数字变色，min 标签一路向左 |

## 怎么练（健身房，蓝图 §2.5-C）

1. 🎯 预测页：**L_COPY 那帧只有一个节点变**（根的值 5→7）——多数人会多选后继节点
2. 盯紫色 min 标签：它从 8 走到 7 的两步，就是"右子树找最小"的实况
3. 白纸推一遍"删 3"会走哪条路线（双子：后继是 4，4 是叶子），再开工具验证
