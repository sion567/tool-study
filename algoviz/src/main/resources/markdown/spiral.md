# 螺线画廊

## 一句话

三种螺线同屏——**等差生长（阿基米德）vs 等比生长（对数/黄金）**，一字之差性格迥异。

## 不变量

- 阿基米德 r = aθ：每圈加固定长度（臂等宽）——唱片纹路、卷纸、蚊香
- 对数 r = e^(bθ)：每圈 ×e^(2πb)——自相似：放大任意倍还是自己（鹦鹉螺、星系旋臂）
- 黄金 r = φ^(2θ/π)：每圈 ×φ——对数螺线的黄金特例（与斐波那契同源）
- 三条线同屏：等距 vs 等比的一字之差

## 画面读法

- 蓝实线 = 阿基米德（匀速扩张）
- 绿虚线 = 对数（加速扩张）
- 橙线 = 黄金（介于两者间的等比）
- 🎯 点选预测：同 θ 处三线的半径排序（θ 大时对数/黄金远超阿基米德）

## 数学史

- 阿基米德（前 3 世纪）：烧罗马战船的传说主角
- 笛卡尔（1638）对数螺线；伯努利把它刻上墓碑："**纵使改变，依然故我**"
- 黄金螺线与斐波那契：黄金矩形无限切割的轨迹

## 怎么练

- 🎯 预测：暂停后猜三条线在下 θ 处的半径排序
- 白纸算：θ=6π 时对数螺线 r = e^1.26×6 ≈ 1908——指数的狂野 vs 阿基米德的 7.4
- 思考：为什么自然偏爱对数螺线？（等比生长 = 尺寸变了形状不变——生长不改变已有部分）
