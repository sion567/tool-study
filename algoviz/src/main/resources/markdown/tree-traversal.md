# 二叉树遍历（前序 / 中序 / 后序）

## 一句话

同一个递归骨架，`visit` 放在三个不同的位置，就得到三种序——**递归不变，位置变**。

## 生活故事

公司层级汇报：进部门先自我介绍再管下属（前序）；先听完所有下属再汇报自己（后序）；中序是 BST 专属彩蛋——**左根右走一遍，出来就是有序的**。

## 不变量（意图层）

- **调用栈 = 从根到当前节点的路径**（右面板看得到：一层一层压，一层一层弹）
- 树上的彩色序号 = 调用树视图：蓝 = 还在栈上，绿 + 序号 = 已访问
- 三种序的唯一区别：`visit` 在 `traverse(left)` 之前、之间、还是之后——**代码里就挪了一行**

## 双视图怎么看（蓝图 M4 的关键设计）

1. **调用栈**（右下变量面板）：压栈 = 进入一个节点，弹栈 = 子树处理完回退。null 也压一帧——那是递归的刹车
2. **调用树**（中间画布）：橙圈 = 栈顶（当前节点），绿 = 已访问，右上角数字 = 访问序号
3. 两个视图对照看：**栈顶走到哪，树上的橙圈就跳到哪**

## 怎么练（健身房，蓝图 §2.5-C）

1. 🎯 预测页：「哪些节点会变？」——注意压栈/弹栈帧：节点只变颜色不变形状
2. 三个序各放一遍，只盯 `visit` 那一行的位置差异
3. 关掉工具，白纸画这棵 7 节点树，分别标出三种序——和画布上的序号对答案
