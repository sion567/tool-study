# 微积分·定积分（黎曼和）

## 一句话

不会求曲线下面积 → 切成矩形用加法近似 → **无限细分就是定积分**。

## 不变量

```
黎曼和 = Σ f(xᵢ)·Δx   （n 个矩形）
∫₀ᵇ f dx = lim(n→∞) 黎曼和
```

## 画面读法

∫₀¹ x² dx（真值 1/3 ≈ 0.3333），左端点矩形：

| n | 矩形和 |
|---|---|
| 1 | 0 |
| 2 | 0.125 |
| 4 | 0.2188 |
| 8 | 0.2734 |
| 16 | 0.3027 |
| 32 | 0.3179 |

矩形翻倍 → 台阶变细 → 和爬向 0.3333（左端点恒低估，从下面逼近）。

## ∫ 的来历

积分符号 ∫ 是拉长的字母 **S**（Sum）——莱布尼茨的手笔。
"无限求和"四个字就刻在这个符号的形状里。

## 微积分基本定理

牛-莱公式：面积 = 原函数端点差。(x³/3)' = x² → ∫₀¹ x² dx = 1/3 − 0。
"无限加法"瞬间变"代入减法"——这就是导数与积分互为逆运算的威力。

## 怎么练

- 白纸算：∫₀¹ x dx 的 n=1,2,4 黎曼和（应收敛到 0.5）
- 思考：为什么左端点矩形恒低估 x²？换成右端点呢？（恒高估——夹逼）
