# 泰勒展开逼近 sin(x)

## 一句话

sin(x) = x - x³/3! + x⁵/5! - …——**项数越多越像，计算器就是这么算 sin 的**。

## 画面怎么读

- **灰线**：真实的 sin(x)
- **彩线**：当前项数的泰勒多项式
- **堆面板**：当前项数 + [0,2π] 全段最大误差

## 逐帧看误差缩小

| 项数 | 多项式 | 最大误差 | 体感 |
|---|---|---|---|
| 1 | x | ~4.8 | 只是条斜线 |
| 3 | x - x³/6 | ~0.53 | 有点像了 |
| 5 | + x⁵/120 | ~0.19 | 半个周期内很像 |
| 7 | - x⁷/5040 | ~0.05 | 几乎重合 |
| 9 | + x⁹/362880 | ~0.008 | 肉眼看不出差别 |

## 不变量（意图层）

- 项数越多，多项式越贴近 sin(x)——每加两项，误差按数量级缩小
- 奇数次幂 + 正负交替 + 阶乘分母——三个零件拼出「多项式版的 sin」

## 为什么重要

- **计算器/CPU 计算 sin 的原理**：不求极限，只算有限项
- 误差可控：项数取多少取决于精度需求
- x 越大收敛越慢——这就是为什么实际实现会先把 x 折算到 [-π, π]

## 怎么练

- 🎯 预测页：给定项数，猜「最大误差」的数量级
- 白纸算 taylorSin(1, 3) = 1 - 1/6 = 0.8333（真实 sin(1) = 0.8415）
- 思考：为什么系数是阶乘分之一？（答：让多项式的各阶导数在 0 点和 sin 完全一致）

## cos 版（同一套思路）

```
cos(x) = 1 - x²/2! + x⁴/4! - x⁶/6! + …   ← 偶次幂，常数项 1 起步
```

与 sin 的全部区别：**次幂从奇变偶、首项从 x 变 1**——符号交替和阶乘分母原封不动。

## 怎么练（cos）

- 白纸算 cos(1) 的前三项：1 - 0.5 + 0.0417 = 0.5417（真值 0.5403）
- 对比 sin(1) 的前三项：1 - 0.1667 + 0.0083 = 0.8417（真值 0.8415）
