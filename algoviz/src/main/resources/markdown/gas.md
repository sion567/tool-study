# 分子动理论·理想气体

## 一句话

40 个分子横冲直撞，弹性碰壁只翻方向不改速率——**压强是亿万次碰壁的统计影子，温度是平均动能的别名**。

## 不变量

- 弹性碰壁：法向速度翻转、切向不变 → 速率不变 → **RMS 恒定 = 温度恒定**
- 压强 ∝ 单位时间单位面积碰壁频率——宏观量 P 的微观出身
- 无相互作用（理想气体假设）：分子只有匀速直线 + 碰壁两件事

## 画面读法

- 蓝点 = 分子（大小相同、速率不同——麦克斯韦分布的采样）
- 边框 = 绝热箱 4×3：撞上就反弹，热量无处进出
- 堆里「累计碰壁」一路涨、「RMS 速度」纹丝不动：方向在洗牌，能量在守恒

## 统计的力量

- 单个分子：牛顿定律管一切，却毫无「温度」「压强」概念
- 亿万分子一起统计：P、V、T 浮出水面——**宏观量是微观的系综平均**
- P·V = NkT 能从纯力学碰壁推导出来：统计力学把两个世界焊在一起

## 历史一击

- 1827 年布朗看到花粉乱舞，1905 年爱因斯坦算出它的统计规律
- **原子真实存在**的第一个过硬证据——之前还只是「有用的假说」

## 怎么练

- 🎲 换种子：分子换一批，RMS 照旧不动——守恒律与运气无关
- 白纸算：分子数翻倍，同温下压强变几倍？（2 倍——P ∝ N，道尔顿分压）
- 思考：绝热压缩为什么升温？（对气体做功 → 平均动能涨 → RMS 涨——本演示的 RMS 就不动了，因为没人对它做功）
