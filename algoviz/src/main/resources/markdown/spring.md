# 力学·弹簧振子

## 一句话

胡克定律 F = −kx → 简谐运动 x = A·cos(ωt)，周期 T = 2π√(m/k)；本演示的真主角是**显式欧拉在偷偷注能量**。

## 不变量

- 精确解能量 E = ½kx² + ½mv² **严格守恒**
- 显式欧拉每步放大 √(1+(ω·dt)²) ≈ 1.005 倍 → 振幅指数增长，3 个周期涨 2.5 倍
- 步长减半 → 注能率平方地变小（~½(ω·dt)²）：数值精度换步数的通则

## 画面读法

- 蓝色折线 = 显式欧拉的离散轨迹（越荡越大的「假振荡」）
- 绿虚线 = 解析解 cos(t)（永远 ±1，能量守恒的真身）
- 堆里：E/E₀ 就是罪证——精确解永远 1.0000，欧拉一路涨

## 欧拉的病根

- 挪位置用的是**旧速度**，拐弯永远慢半拍 → 每步都在往外圈漂
- 药方一：步长调小（治标）
- 药方二：**辛积分**（半隐式欧拉：先更新 v 再挪 x）——漂移从指数增长变有界振荡，物理引擎标配

## 怎么练

- 白纸算：m 加 4 倍，周期变几倍？（2 倍——T ∝ √m）
- 思考：为什么游戏里的弹簧越弹越夸张？（八成是显式欧拉没换）
- 对比：本演示的 RK4 在双摆里能量漂移 ≈ 0——精度之王也有守恒盲区
