# 数值方法·二分法

## 一句话

f(a)·f(b) < 0 → 根被夹住 → 取中点按符号扔一半——**每步误差预算 ÷2**。

## 不变量

- 介值定理：连续函数从负到正必过零——合法性全靠它
- 每步信息量 +1：k 步 = log₂ 收敛，k 位精度跑 k 步

## 画面读法

- 蓝曲线 = f(x)，橙竖线 = 当前中点，橙点 = f(中点)
- 区间 [a,b] 十步从宽 1 缩到 1/1024

## 与牛顿迭代的分工

| | 二分法 | 牛顿迭代 |
|---|---|---|
| 收敛 | 线性（每步 1 位） | 平方（每步位数翻倍） |
| 要求 | 连续 + 变号 | 可导 + 好初值 |
| 风险 | 无（必收敛） | 可能发散 |

**工程组合拳**：二分兜底保鲁棒，牛顿冲刺抢速度。

- 思考：为什么二分不可能比 O(log₂(1/ε)) 更快？（每步最多 1 比特信息）
