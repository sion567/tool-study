# 归并排序

## 一句话

分而治之：劈成两半各自有序，再双指针比小合并——**稳定 O(n log n)，没有退化情况**。

## 生活故事

两叠各自排好序的牌合成一叠：每次翻两张比大小，小的先放——**谁小谁先进，一双手就够了**。

## 不变量（意图层）

- 合并完成后 [lo,hi] 有序——左右两半各自有序，双指针比小逐个放进 tmp
- **稳定性**：`a[i] <= a[j]` 时左边的先进 → 相等元素保持原顺序

## 画面怎么读

- 右面板：递归栈 ms(lo,hi) 逐层压弹
- 堆面板：`@1 a` 主数组 + `@2 tmp` 辅助数组逐格生长
- 黄圈 = 本步写入的格子

## 逐行看

1. `ms(a, lo, mid)` / `ms(a, mid+1, hi)`：分——递归到单元素
2. `tmp[k++] = (a[i] <= a[j]) ? a[i++] : a[j++]`：治——一行双指针比小
3. 两个 while：一边扫完后另一边整体搬入
4. 写回主数组：tmp 只是草稿

## 怎么练

- 🎯 预测页：合并阶段问「tmp 哪个格子会写数」
- 对比快排：快排先干活后递归（分区在先），归并先递归后干活（合并在后）
- 白纸推 {5,2,9,1,5} 的完整递归树和每层合并结果
