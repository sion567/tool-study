# 复利与 e

## 一句话

结算越频繁收益越高，但有**上限**：(1+1/n)ⁿ → e = 2.71828——自然底数出身于记账。

## 不变量

- (1+1/n)ⁿ **单调递增有上界** → 极限存在（单调有界定理）
- n→∞ = 连续复利：A = P·e^{rt}

## 画面读法

- 橙点 = 各结算频率的年终值（2 → 2.25 → 2.44 → … → 2.7077）
- 绿虚线 = 极限 e
- 蓝曲线 = 连续函数 (1+1/x)ˣ 的形状

## 伯努利的发现（1683）

100% 年利率：年结 ×2；半年 ×2.25；每季 ×2.44；每月 ×2.61；每天 ×2.7146；每秒 ×2.71812——
**多结一次几乎不再多赚**。这个"上限"值得一个专属符号：e。

## 同族曲线

放射性衰变、人口增长、RC 电路放电——凡"增长速率正比于当前量"者皆姓 e。
(e^x)' = e^x：唯一导数等于自己的函数（差个常数系数）。

## 怎么练

- 白纸算 n=2 和 n=4 的终值（2.25 与 2.4414）
- 思考：年利率 8% 连续复利，10 年后是几倍？（e^{0.8} ≈ 2.2255）
