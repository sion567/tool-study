# 反应过程·勒夏特列平衡

## 一句话

正逆速率此消彼长**夹出平衡**——平衡是「速率的握手」，不是「浓度的对半」；扰动后系统向削弱扰动的方向重新握手。

## 不变量

- K = k_f/k_r：速率常数一除，热力学量出炉——**K 只认温度**
- 平衡判据：v_f == v_r（净流量为零），分子还在来回撞（动态平衡≠静止）
- Q = 「此刻的 K」：Q>K → 逆反应接管；Q<K → 正反应接管——系统永远奔向 Q=K

## 画面读法

- 蓝线 = v_f（从 max 掉头向下），绿虚线 = v_r（从 0 爬升）——两线咬合即平衡
- ⚡ 扰动帧：瞬间注入产物 C，v_r 突跳反超——剪刀差换向
- 🎯 看堆里 Q：先逼近 K，扰动后飞离 K，再一步步爬回来——这就是勒夏特列的全过程

## 三幕剧（默认参数）

- 幕一（0~4s）：v_f=0.5 → 0.125，v_r=0 → 0.125，平衡时 [C]=0.5
- 扰动：C 注入 +0.6 → Q 飙过 K → 逆反应主导
- 幕三：C 被消耗、A/B 回升 → 新平衡——组成变了，K 没变

## 工业注释

- 合成氨：不断移走 NH₃（Q<K）逼反应不停右移——勒夏特列原理的 billion-dollar 应用
- 缓冲溶液：少量酸碱进来 Q 几乎不动——平坦区抗干扰

## 怎么练

- 🎲 预测：暂停在扰动后一帧，猜 v_f/v_r 谁在上——你就是在判 Q 与 K 的大小
- 白纸算：K=2 时平衡 [C]？（解 2(1−C)²=C → C=0.5——与模拟对照）
- 思考：为什么加压有利于合成氨？（N₂+3H₂→2NH₃ 气体分子数减少——勒夏特列连压强都管）
