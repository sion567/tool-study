# 七桥问题·欧拉路径

## 一句话

奇顶点 > 2 → 不可能不重复走遍所有桥——**欧拉 1736 年用一次抽象终结了全城的尝试**，图论就此诞生。

## 不变量

- 每次过桥"进"与"出"成对消耗 2 度
- 中间点必须偶数度；奇点只能当起点/终点（最多 2 个）
- **连通图有欧拉路径 ⟺ 奇顶点数 ∈ {0, 2}**

## 画面读法

- 原局：度数 3,3,5,3 → **四个奇顶点** → 数学上盖棺
- 拆一座桥：度数 2,3,5,2 → 两个奇点（南岸、岛）→ 从南岸走到岛
- 逐桥走完：南岸→东岸→岛→南岸→岛→北岸→岛

## 抽象的威力

"陆地和桥" → "点和边"：距离、形状全部无关，只剩连接关系。
几何问题瞬间变成**计数问题**（数奇点）。

## 算法遗产

Hierholzer 算法 O(E) 找欧拉路径。应用：DNA 测序拼接、任务调度、笔画输入。

## 怎么练

- 白纸数七桥版的度数，验证四奇点
- 思考：什么时候有欧拉**回路**（回到起点）？（0 个奇点）
