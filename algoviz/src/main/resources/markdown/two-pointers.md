# 双指针（两数之和·有序版）

## 一句话

有序数组找两数和：**一头一尾，小了左移右、大了左移左**——每个指针各走一遍 O(n)。

## 不变量

lo < hi 期间：若 a[lo]+a[hi] < target，则 a[lo] 配任何剩余数都小 → lo 可安全排除；
> target 同理排除 hi——每步砍掉一个候选，正确性无遗漏。

## 演示数字

a = {1,2,5,5,9,12,15}，target=14：lo=0,hi=6（和16>14 → hi−）… 相遇前命中 2+12。

## 对比哈希法

| | 双指针 | 哈希 |
|---|---|---|
| 前提 | 需有序 O(n log n) | 无序可用 |
| 空间 | O(1) | O(n) |

## 怎么练

- 白纸走本例的指针轨迹（7 步）
- 变形：三数之和 = 固定一个 + 双指针；接雨水 = 双指针取矮侧
