# 重构·提取方法（Extract Method）

## 一句话

把一段代码变成**名字讲得清它**的方法——方法名就是注释。

## 反例痛点

20 行方法混"校验 + 计算 + 打印"：

- 读懂一次 5 分钟，下次还得重读
- 改打印 → 先在 20 行里翻出"哪几行是打印"——改动半径 = 整个方法

## 正例

```
process(a):
    validate(a)     // 名字即摘要
    return compute(a)
```

调用处 2 行读完主逻辑；改任何一件事直奔对应方法——
**行为零变化（重构的定义），阅读/修改成本从"全方法"缩到"单方法"**。

## 判据

给这段代码起个名字——**起不出（要带"和"）就还没切干净**。

## 怎么练

- 找最长的方法，按"这几行在干同一件事吗"切段，逐段提取
- 提取后通读调用方：能像读摘要一样读下去，就对了
