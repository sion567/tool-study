# 路径总和

## 一句话

根→叶路径和 = 目标？前序遍历边走边加，到叶子一判即知。

## 不变量

sum 恒等于根到当前节点的路径和。
递归下传 sum + node.val（或等价地传 target − node.val），
**栈帧链就是当前路径**——不用真的存路径数组。

```
        5
       / \
      3   8
     / \ / \
    1  4 7  9
```

叶子和：9 / 12 / 20 / 22 → 目标 12 命中 5→3→4。

## 关键点

- **只在叶子判定**：中途节点的部分和不是完整路径
- `node == null` 不是叶子——叶子是 `left == null && right == null`
- 命中后一路 `return true` 短路回穿，路径上的节点全部保持高亮

## 为什么不用存路径

每层栈帧天然记着"我是谁、父是谁"——回溯时弹栈就等于把路径倒着走回去。
需要**输出**路径时才要显式 List（进 push、退 pop）。

## 延伸

- 路径总和 II：输出所有命中路径 → 显式维护 path 列表
- 路径总和 III：路径不必从根开始 → 前缀和 + 回溯（树上版两数之和）

## 怎么练

- 白纸默写三行骨架：null 判、叶子判、左右递归
- 变形练习：target 从 12 改成 20，跟踪 sum 标签一路怎么变
