# 组合构造·约瑟夫环

## 一句话

n 人围圈报数报到 k 出列——**模拟 O(n²) 给直觉，递推 f(j) = (f(j−1)+k) mod j 给答案**，两种解法必须握手。

## 不变量

- 报数取模：数到尾巴绕回头——圆圈没有起点，模运算天生是圆圈的代数
- 递推核心：j 人圈删掉出列者后变成 j−1 人圈 → **f(j) = (f(j−1)+k) mod j**——小圈答案唯一确定大圈答案
- 模拟与公式必须给出同一个幸存者：两种世界观互相校验

## 画面读法

- 第一幕：柱子 = 圈中人（编号即柱高），变 0 的柱 = 出列者；每步事件文本列出本轮报数序列
- 第二幕：同一排柱子变成 f 表——f(1)=0 从最左滚到 f(n)，最后值 = 幸存者位置
- 🎯 点选预测：第一幕猜「谁出列」（你得自己数活人 mod k）；第二幕猜「f 表哪格被填」

## 模拟 vs 递推

- 模拟：忠实重演每一轮，O(n²)——n=12 秒懂，n=10⁸ 就死了
- 递推：不重演，只「记忆」小圈答案，O(n)——1 亿人报到 9 出列，毫秒出答案
- 这就是「会做」和「会算」的差别：数学归纳法的算法化身

## 怎么练

- 手算：n=5, k=2 → f: 0→2→4→3→1？自己滚一遍 f 表验证
- 🎲 换 n、k 再跑——注意第二幕的 f 表永远比模拟「先知道答案」
- 思考：为什么 f(j) 要 mod j 而不是 mod n？（圈在缩：j 人圈的位置空间是 0..j−1）
