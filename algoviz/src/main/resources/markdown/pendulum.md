# 微积分应用·钟摆

## 一句话

小角度摆动 = **简谐运动**：θ(t) = θ₀·cos(ωt)，周期 T = 2π√(L/g)——与质量无关。

## 不变量

- 微分方程 θ'' = −(g/L)·sinθ **没有初等解**
- 小角度近似 sinθ ≈ θ → 方程线性化 → 简谐运动有闭合公式
- T = 2π√(L/g)：调摆长 = 调音（摆钟原理）

## 画面读法

- 橙点 = 摆锤，橙线 = 摆臂（悬挂点在原点上方）
- 蓝弧 = 摆锤走过的轨迹（一段圆弧，被来回描）
- t = T/2 时 θ = −30°（反相）：cos 正是干这个的

## 线性化的代价与回报

- 回报：丢掉 sin 的非线性 → 得到能写在纸上的周期公式
- 代价：角度 >15° 后周期开始变长（真实钟摆慢一点点）→ 严格解需要椭圆积分

## 同一个方程的家族

弹簧振子、LC 电路振荡、桥梁共振——全部是 x'' = −ω²x 的变体。
**简谐运动是物理学的"元音字母"**。

## 怎么练

- 白纸算：L 加 3 倍周期变几倍？（√3 ≈ 1.73 倍）
- 思考：月球上（g 小）摆钟变快还是变慢？
