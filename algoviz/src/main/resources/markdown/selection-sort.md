# 选择排序

## 一句话

每一轮从无序区**挑最小的**，跟无序区队头交换——交换次数最少（最多 n-1 次）。

## 生活故事

扑克牌摊在桌上理牌：一眼扫过去挑最小的抽出来放左边，再在剩下的里挑最小的接着放……「扫一遍挑一个」就是内层循环。

## 不变量（意图层）

- 每轮结束：**前 i+1 个位置是全数组最小的 i+1 个，且有序** → 头部绿区从左往右生长
- `min` 是「卫冕最小值」的下标：内层就是挑战者 `a[j]` 不断挑战卫冕者 `a[min]`
- 交换前先把 `a[i]` 存进 `t`——和冒泡同一招：**先记住再覆盖**

## 什么时候用 / 代价

- O(n²) 比较，但只有 O(n) 交换 → 适合「交换成本高」的场景（如写 Flash）
- 不稳定（长距离交换会打乱相等元素）；数据规模大时同样不行
