# 概率·骰子与钟形

## 一句话

一枚骰子**平坦**，两枚相加**拔地成钟**——中心极限定理的第一次露面。

## 不变量

- 一枚：每面 1/6（均匀）
- 两枚之和：卷积分布，P(7) = 6/36 ≈ 16.7% 最高
- 对称：P(s) = P(14−s)

## 卷积直觉

和为 7 的写法有 6 种（1+6/2+5/…/6+1），和为 2 只有 1 种（1+1）——
**路径越多的结果概率越大** → 中间自然隆起。

## 中心极限定理（CLT）

独立随机量相加，无论原来什么形状，n 大时都走向正态。
身高/考试分数/测量误差 = 无数独立因素的"和"——所以处处钟形。

## 怎么练

- 白纸列两枚之和的 36 种组合，验证 P(7)=6/36
- 变形：三枚之和（216 组合）画直方图——更瘦更接近正态
