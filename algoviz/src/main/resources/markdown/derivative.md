# 微积分·导数

## 一句话

导数 = **割线斜率在 Δx→0 时的极限** = 该点的瞬时变化率 = 切线斜率。

## 不变量

```
割线斜率 = (f(x₀+Δx) − f(x₀)) / Δx      ← 平均变化率
f'(x₀)   = lim(Δx→0) 割线斜率            ← 瞬时变化率
```

## 画面读法

f(x)=x²，定点 P(1.5, 2.25)，Δx 逐次减半：

| Δx | 割线斜率 |
|---|---|
| 1 | 4 |
| 0.5 | 3.5 |
| 0.25 | 3.25 |
| 0.125 | 3.125 |
| →0 | **3 = f'(1.5) = 2×1.5** |

割线绕着 P 转，最后"贴"在曲线上——那条贴住的线就是切线。

## 两个视角

- **几何**：切线斜率（画面上那条线）
- **物理**：瞬时速度（平均速度的极限）——车速表读的就是导数

## 为什么能"背公式"

每点都做无限逼近太慢——牛顿/莱布尼茨把极限过程压缩成规则（幂函数↓幂、乘积法则……）。
f(x)=x² → f'=2x 的"f'=nxⁿ⁻¹"就是这条极限路的打包版。

## 怎么练

- 白纸算：f=x²，x₀=1 的割线斜率表（Δx=1, 0.5, 0.25），验证收敛到 2
- 思考：Δx 取 0.0000001 一定更准吗？（浮点舍入误差会反噬——数值导数用中心差分）
