# 杨辉三角

## 一句话

`C(n,k) = C(n−1,k−1) + C(n,k−1)`——每个数都是肩上两数之和，**这是 DP 的祖先**。

## 不变量

- 两腰恒为 1（边界条件）
- 行内对称：C(n,k) = C(n,n−k)
- 第 n 行和 = 2ⁿ（每行每数分裂成下面两个 → 一颗二叉树翻倍）

## 画面读法

- 绿 = 已定格的行，黄圈 = 刚生成的行
- 事件里明示"肩上两数"：如第 4 行的 6 = 3 + 3

## 藏在图里的数列

- 第 2 斜线 = 自然数 1,2,3,4…
- 第 3 斜线 = 三角形数 1,3,6,10…
- 斐波那契也在对角线上！

## 与 DP 的关系

`dp[n][k] = dp[n-1][k-1] + dp[n-1][k]`——状态转移方程一模一样。
会打杨辉三角 = 会了二维 DP 的全部套路。
